# Crest v1.5.12 发布说明

发布日期：2026-06-24

Crest v1.5.12 是 v1.5.11 之后的稳定补丁版本，重点修复数据大屏、表单组件、查询框、媒体资源和图片类组件配置上传图片后展示不生效的问题。本版本没有新增数据库结构、系统参数或初始化数据变更；已有 v1.5.11 环境只需要替换前后端镜像或使用应用镜像升级包。

## 离线包

`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 修复内容

- 修复数据大屏画布配置上传背景图片后，预览和展示样式没有稳定应用背景图的问题。
- 修复表单组件、查询框及通用组件背景配置使用外部图片时，背景图可能被组件内部样式覆盖的问题。
- 修复标题类组件背景图使用 CSS `background` 简写时，上传图片路径包含空格等字符可能解析不稳定的问题。
- 修复前端 Nginx 静态资源后缀规则优先匹配 `/api/v1/static-resource/` 图片请求，导致上传图片、媒体资源和图片类插件资源访问 404 的问题。

## 升级说明

全新安装不需要手动执行 `upgrade-sql/` 中的 SQL。

已有 v1.5.11 环境升级到 v1.5.12 时，只需要替换前后端镜像或使用 v1.5.12 应用镜像升级包，不需要新增升级 SQL。

从 v1.5.8 升级到 v1.5.12 时，只需要替换前后端镜像或使用应用镜像升级包，不需要新增升级 SQL。

从 v1.5.7 升级到 v1.5.12 时，请先执行：

```text
upgrade-sql/v1.5.7_to_v1.5.8.sql
```

执行升级 SQL 后，再替换 v1.5.12 前后端镜像。生产环境升级前建议完成数据库备份、运行目录备份和关键报表导出。
