# Crest v2.0.1 发布说明

发布日期：2026-06-25

Crest v2.0.1 是 2.0 系列维护版本，重点完成元数据表命名统一、模板文件后缀调整、运行配置标识清理，并修复可视化背景图片渲染问题。

## 主要变化

- 统一 Crest 自有元数据表命名，表名按业务域和用途归类；Quartz `QRTZ_*` 表保持不变。
- 模板文件统一使用 `.crest` 后缀，导入入口、后端校验和提示文案保持一致。
- 运行配置中的数据集参数字段 ID 和树层级值改为 Crest 语义，升级脚本会迁移已保存配置。
- 产品文案调整为更直接的业务表达，减少实现细节暴露。

## 修复内容

- 修复数据大屏和仪表盘背景图片在部分样式组合下渲染不稳定的问题。
- 修复前后端分离部署下上传图片静态资源路由不一致的问题。

## 升级说明

升级前必须完成以下准备：

- 备份 Crest 系统库；
- 备份运行目录和 `.env`；
- 确认当前系统库类型：MySQL、OceanBase MySQL 或 OceanBase Oracle；
- 确认所有 Crest 服务已停止或处于维护窗口。

全新安装不需要手工执行 `upgrade-sql/`。

从 v2.0.0 升级到 v2.0.1 时，按系统库类型执行以下脚本。

MySQL 系统库：

```text
upgrade-sql/v2.0.0_to_v2.0.1_metadata_tables_mysql.sql
upgrade-sql/v2.0.0_to_v2.0.1_runtime_identifiers_mysql.sql
```

OceanBase MySQL 系统库：

```text
upgrade-sql/v2.0.0_to_v2.0.1_metadata_tables_ob_mysql.sql
upgrade-sql/v2.0.0_to_v2.0.1_runtime_identifiers_ob_mysql.sql
```

OceanBase Oracle 系统库：

```text
upgrade-sql/v2.0.0_to_v2.0.1_metadata_tables_ob_oracle.sql
upgrade-sql/v2.0.0_to_v2.0.1_runtime_identifiers_ob_oracle.sql
```

从 v1.5.11 升级到 v2.0.1 时，先执行 v2.0.0 对应数据库类型的增量 SQL，再执行上面的 v2.0.1 SQL。从 v1.5.7 及更早版本升级时，先执行历史升级 SQL，再按同样顺序升级到 v2.0.1。

## 验证范围

本版本已执行以下验证：

- 后端针对性测试：数据集参数字段 ID、模板后缀、静态资源读取、数据集同步查询；
- 前端类型检查、背景图片样式检查、静态资源路由检查和 v2.0.1 发布校验；
- MySQL 独立库执行 v2.0.0 到 v2.0.1 升级脚本，验证表名迁移和运行配置标识迁移；
- OceanBase Oracle 独立 schema 执行 v2.0.0 到 v2.0.1 升级脚本，验证表名迁移和运行配置标识迁移。
