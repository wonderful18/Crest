## 修复明细

### HIGH-1 SQL 注入（系统变量）

- **`$crest[]` 系统变量参数化**（HIGH-1-B）：原实现将系统变量值以字符串拼接方式写入 SQL，存在注入风险。现改为 `?` 占位符参数化绑定（`TableFieldWithValue`，VARCHAR），由底层 PreparedStatement 按位置绑定，注入不可达。下游绑定逻辑无需改动，向后兼容。

### HIGH-1 只读校验加固

- **`validateReadQuery` 写原语拦截**（HIGH-1-C）：在原有 SELECT/WITH/SHOW/DESC/EXPLAIN 前缀校验与单语句校验之上，新增写/DDL 原语词边界拦截（`insert`/`update`/`delete`/`drop`/`alter`/`create`/`truncate`/`grant`/`revoke`/`merge`/`exec`/`call`/`replace`）以及 `into outfile`/`into dumpfile`/`into table`/`for update` 拦截，纵深防御只读上下文下的写操作。
- 保留 `UNION / UNION ALL`：union 数据集生成依赖该语法，禁用会破坏产品功能，故未拦截。

### MEDIUM-1 分享链接密钥隔离

- 无密码分享（创建与改密）现在分配**独立随机密钥**（32 字节 base64url，URL-safe），不再回落全局 fallback 密钥，避免跨资源伪造分享令牌。`ShareSecretManage` 新增 `generateRandomSecret()`。

### MEDIUM-2 Token 查库缓存

- `CrestUserManage.secretByUid`（token 签名密钥查询）新增 60 秒 TTL 缓存（零新增依赖：`ConcurrentHashMap` + 守护线程定时清理），降低每请求回查数据库的开销。
- 所有改密码路径（`edit` / `resetPwd` / `modifyPwd` / 密码自动升级 / SSO 创建 / 管理员初始化）在写入新密码后立即显式失效缓存，保证“改密即失效旧 token”的语义。

## 验证

- 新增/补充 4 个测试类，共 28 个用例全部通过：
  - `SqlSecurityPolicyTest`：只读校验、保留 UNION、拦截写原语与文件写出。
  - `ShareSecretManageTest`：随机密钥唯一性与 URL-safe、按分享隔离。
  - `CrestUserManageTest`：缓存命中、失效后回查、resetPwd 失效。
  - `SqlParserUtilsSecurityTest`：系统变量参数化、注入载荷不进入 SQL 文本。

## 升级说明

- 从 v1.5.18 升级到 v1.5.19 只需要替换前后端镜像，不需要新增升级 SQL。

## 兼容性

- 系统变量绑定语义与原有 `?` 占位符一致，数据集/看板查询行为不变。
- 分享链接：无密码分享的访问密钥变更为每资源独立随机密钥；已有带密码分享不受影响。
- Token 缓存：改密后旧 token 在 60 秒 TTL 兜底后必然失效，且显式失效保证改密即时生效。
