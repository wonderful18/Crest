# v1.5.41

发布日期：2026-09-02

v1.5.41 是 v1.5.40 之后的缺陷修复版本。**修复投产窗口日历不显示真实投产日期和投产内容、始终回退 mock 假数据的缺陷。** 本版本没有新增数据库结构，无需执行升级 SQL。

## Bug 修复

### 投产窗口日历不显示真实投产数据（根因修复）

v1.5.39 ~ v1.5.40 持续定位该问题：v1.5.40 部署后前后端日志对照确认，后端 `calcData` 正常返回了 `fields=3, tableRow=20`，但前端解析后 `fields` 仍为空，最终回退 mock。

**根因**：前端 `getData` API（`chart.ts`）返回的是 **view 对象本身**（HTTP 响应体的 `data` 字段），而 `fields` 和 `tableRow` 嵌套在 **`view.data`** 中。普通图表（`ChartComponentS2.vue`）正确取 `res?.data`，但投产日历 `Component.vue` 的 `parseData` 直接从 `res` 顶层取 `fields`/`tableRow`，导致永远取不到数据，回退 mock。

- **修复**：`Component.vue` `parseData` 中数据来源从 `res` 改为 `res?.data || res`，`fields`/`tableRow` 从 payload 中取；结构体检日志同步增加 `dataKeys` 便于后续排查
- **同步修正**：`calcData` 中诊断日志的返回字段提取（`res?.data?.fields`）、`curViewInfo.curFields` 赋值（`res.data.fields`）同步修正层级

涉及：`core/core-frontend/src/custom-component/deploy-calendar/Component.vue`

> 验证方式：部署后刷新投产窗口日历页面，前端 console `[DeployCalendar] 0. 后端返回结构体检` 中 `fieldsLen` 应 > 0，`[DeployCalendar] 9. 行数统计` 中 `解析成功` 应 > 0，日历应显示真实投产日期圆点。
