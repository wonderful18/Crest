# v1.5.39

发布日期：2026-08-31

v1.5.39 是 v1.5.38 之后的修复与增强版本。修复分享链接打开又弹「系统有升级」提示的回归；为柱状图辅助线名称新增图例显示；并为投产窗口日历远端不显示真实投产数据的问题加入前后端诊断日志以定位根因。**本版本没有新增数据库结构，无需执行升级 SQL。**

## 新功能

### 柱状图辅助线名称图例化
柱状图高级功能的辅助线，名称原先直接标注在线上（text annotation），现改为以**图例**形式显示，并支持配置显示位置。

- **显示图例开关**：默认开启，辅助线名称以图例形式展示；可关闭
- **图例位置**：支持 上/下/左/右 四向配置
- **显示线上文字开关**：默认关闭（仅图例显示名称），可开启以在线上保留文字标注
- **单独图例区**：辅助线图例独立于柱状图本身的系列图例，各自配置位置。因 g2 v4 原生 legend 不支持同图两个独立图例区，辅助线图例采用自定义 DOM 实现（绝对定位在图表容器内），不影响系列图例
- 生效范围：柱状图（bar）与条形图（horizontal-bar）；辅助线渲染函数通用，后续可一行调用扩展到其他图表

涉及：`ChartAssistLineCfg` 新增 `legendEnable`/`legendPosition`/`showLineText` 字段及默认值；`AssistLine.vue` 配置 UI；`common_antv.ts` 线上文字按开关控制 + 新增 `getAssistLineLegend`/`renderAssistLineLegend`；`bar.ts`/`horizontal-bar.ts` 渲染后挂载图例；中英文 i18n。

## Bug 修复

### 分享链接打开又弹「系统有升级」提示（回归）
v1.5.32 曾修复分享链接（`#/link/xxx`）打开时不弹系统升级提示框，v1.5.37 之后复现。

- **根因**：v1.5.37 给预览/分享态补发了 `/chart-data/data` 请求（修复懒加载导致分享态不发 data 请求的 P0），暴露了 v1.5.32 那个分享态拦截判断的时机漏洞。原判断 `router.currentRoute.value.path.startsWith('/link/')` 依赖 vue-router 异步导航状态，在 reload 后 / 路由未就绪时 `path` 可能仍非 `/link/`，拦截落空而误弹升级框
- **修复**：改为同步读 `window.location.hash`，复用项目已有的 `isPublicLinkHash` 判断函数（`publicLinkJump.mjs`）。hash 模式下 `window.location.hash` 同步可读，不受导航就绪时机影响。普通编辑态行为不变

涉及：`core/core-frontend/src/config/axios/service.ts` 的 `executeVersionHandler`。

## 诊断增强

### 投产窗口日历远端不显示真实投产数据
生产环境投产日历组件只显示 mock 假数据，不显示真实投产日期。经排查前端日志确认后端 `/chart-data/data` 返回空的 `fields`/`tableRow`，前端解析拿不到字段而回退 mock。

- **根因方向**：后端 `ChartDataManage.calcData` 按列权限/engineFieldName 过滤字段时（第 151 行 `removeIf`），把投产日历绑定的日期/内容/类型列全部删除，导致返回空 fields。最可能是真实数据集对这些列配了列权限（测试数据集未配故正常），或数据集字段被重建导致 engineFieldName 对不上
- **本次加入诊断日志**，便于在远端确认根因，暂不改动后端过滤逻辑：
  - 前端 `Component.vue`：返回结构体检、传出场段 vs 后端返回字段对比、`fields` 空 / `dateEng` 空 / 日期解析失败 各分支诊断
  - 后端 `ChartDataManage.java`：列权限过滤处加 WARN 日志，记录被过滤字段的 id 与 engineFieldName（仅有字段被移除才记录，普通图表不刷屏）

> 部署后看后端日志 `[calcData] 轴=... 被列权限/engineFieldName 过滤掉 N 个字段` 即可确认是列权限还是 engineFieldName 不匹配，再决定后续修复方案。
