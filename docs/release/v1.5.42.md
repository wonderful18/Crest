# v1.5.42

发布日期：2026-09-02

v1.5.42 是 v1.5.41 之后的缺陷修复与功能优化版本。**修复投产窗口日历只显示前20条投产数据的问题，并将"投产内容"字段更名为"关联系统"、支持同一天内相同系统名称去重。** 本版本没有新增数据库结构，无需执行升级 SQL。

## Bug 修复

### 投产窗口日历只返回前20行数据

v1.5.41 修复了投产日历不显示真实数据的问题（前端 parseData 取错响应层级），但部署后发现后端只返回20行数据，数据集上千行投产记录只展示了前20条。

**根因**：投产日历复用 `table-info`（明细表）查询通路，明细表有分页机制。`TableInfoHandler.customFilter` 会根据视图 `basicStyle.tablePageMode` 判断是否分页：当 `tablePageMode == "page"` 时设置 `goPage=1, pageSize=tablePageSize`（默认20），SQL 被加 `LIMIT 20 OFFSET 0`。投产日历把视图 type 改成 `table-info` 时未修改分页模式，继承了原视图的分页配置，导致只返回20行。

- **修复**：`Component.vue` calcData 构造请求时，强制将 `basicStyle.tablePageMode` 设为 `'all'`（非分页），后端走 `goPage=null / pageSize=null` 分支，SQL 不加 LIMIT，返回全量投产数据

涉及：`core/core-frontend/src/custom-component/deploy-calendar/Component.vue`

> 验证方式：部署后刷新投产窗口日历页面，后端日志 `[calcData] buildChart出口` 中 `originData行数` 和 `tableRow` 应等于数据集实际投产记录数（不再是20），日历应显示全部投产日期圆点。

## 功能优化

### "投产内容"字段更名为"关联系统"，并支持同一天内系统名称去重

投产日历第二个绑定字段（yAxis）原标签为"投产内容/维度"，现更名为"关联系统/维度"，更贴合实际使用场景（每条投产记录关联一个业务系统）。

同时，当数据集中同一天存在多条相同系统名称的投产记录时，前端 parseData 会自动去重，popover 中同一天同一系统只显示一条，避免重复刷屏。

- **修改**：
  - i18n 中英文：`content_field` 由"投产内容 / Deploy Content"改为"关联系统 / Related System"
  - `Component.vue` parseData：同一天内按系统名称（原 content 字段）去重，空值也参与去重
  - `deploy-calendar.ts`：字段注释同步更新

涉及：
- `core/core-frontend/src/locales/zh-CN.ts`
- `core/core-frontend/src/locales/en.ts`
- `core/core-frontend/src/custom-component/deploy-calendar/Component.vue`
- `core/core-frontend/src/views/chart/components/js/panel/charts/others/deploy-calendar.ts`

> 验证方式：编辑投产日历组件，字段选择器第二个字段显示"关联系统/维度"；绑定含重复系统名称的数据集后，同一天 popover 中相同系统只出现一次。
