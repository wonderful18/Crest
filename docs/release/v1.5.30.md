# v1.5.30 发布说明

v1.5.30 是 v1.5.29 之后的功能改进版本。新增数据大屏弹窗区查询按钮位置可配置(右上/右下)并带「高级查询」文字标签,并补全数据大屏分享链接仍显示图表悬浮导出按钮的问题。**本版本没有新增数据库结构,无需执行升级 SQL。**

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.30` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.30` |

## 新增

### 弹窗区查询按钮位置可配置 + 高级查询标签

- 数据大屏「显示弹窗区查询按钮」开启后,查询按钮此前固定在右下角且只有 Filter 图标。现可在画布设置面板选择按钮位置(右上 / 右下),按钮增加「高级查询」文字标签,样式自适应宽度。
- `CanvasBaseSetting.vue` 新增「查询按钮位置」单选项(`topRight`/`bottomRight`),仅当 `popupButtonAvailable` 为真时显示。
- `canvasUtils.ts` 的 `historyAdaptor` 兼容 `popupButtonPosition`,旧画布默认 `bottomRight`。
- `canvas-filter-btn/Component.vue` 接收 `position` prop,按 `pos-topRight`/`pos-bottomRight` 定位;按钮增加「高级查询」文字标签,样式自适应宽度。
- `CrestPreview.vue` 透传 `canvasStyleData.popupButtonPosition` 给 `canvas-filter-btn`。
- `locales/en.ts`、`zh-CN.ts` 新增 `pop_button_position`/`pop_button_position_top`/`pop_button_position_bottom` 文案。

## 修复

### 数据大屏分享链接仍显示图表悬浮导出按钮

- v1.5.29 仅隐藏了放大视图(`UserViewEnlarge.vue`)内的导出按钮,但每个图表悬浮工具条上的独立导出箭头按钮(`ComponentEditBar.vue`)未加守卫,数据大屏分享链接仍显示。
- 修复:`ComponentEditBar.vue` 独立导出箭头 `el-dropdown` 的 `v-if` 增加 `dvInfo.type !== 'dataV'` 条件;`UserViewEnlarge.vue` 放大视图的图片导出按钮/像素选择/分割线同步补齐 `dvInfo.type !== 'dataV'` 条件。数据大屏场景下不再渲染导出按钮。
