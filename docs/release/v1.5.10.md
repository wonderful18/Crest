# Crest v1.5.10 发布说明

发布日期：2026-06-13

Crest v1.5.10 是 v1.5.8 之后的稳定补丁版本，合并菜单国际化、应用模板本地导入和应用模板导入导出完整性修复。v1.5.9 不作为稳定交付版本；已有 v1.5.8 环境应直接升级到 v1.5.10。

## Release 附件

```text
crest-offline-v1.5.10-linux-amd64.tar.gz
crest-offline-v1.5.10-linux-arm64.tar.gz
crest-app-images-v1.5.10-linux-amd64.tar.gz
crest-app-images-v1.5.10-linux-arm64.tar.gz
crest-source-v1.5.10.tar.gz
crest-v1.5.10-checksums.txt
crest-app-images-v1.5.10-checksums.txt
```

GitHub Release 页面仍会自动提供 `Source code (zip)` 和 `Source code (tar.gz)`。`crest-source-v1.5.10.tar.gz` 是发布流程额外生成的命名源码包，便于归档和交付。

## 离线包

`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 新增内容

- 数据大屏和仪表盘资源列表支持“导入应用模板”，可上传 `.DET2` 或 `.DET2APP` 文件并进入编辑器。
- 应用模板导入后保留数据源、数据集、图表、联动和下钻配置，保存时继续使用现有应用映射流程绑定目标环境资源。

## 修复内容

- 修复后端默认语言包缺少菜单 key 时，工作台、数据准备、系统管理等菜单显示 `i18n_menu.*` 的问题。
- 补齐简体中文、繁体中文、英文和默认语言包的菜单翻译，并增加菜单语言包完整性测试。
- 修复 `.DET2`、`.DET2APP` 文件无法通过本地文件导入创建数据大屏或仪表盘的问题。
- 修复外部应用模板导入时未保留模板版本和应用映射数据，导致数据源、数据集映射流程无法继续的问题。
- 修复历史模板缺少 `scaleHeight` 时导入后画布高度缩放可能异常的问题。
- 修复 `.DET2APP` 应用模板导入保存时只保留外部链接，内部大屏跳转配置未写入的问题。
- 修复应用模板导入后跳转源图表 ID 未按新图表 ID 映射，导致点击指标无法匹配跳转配置的问题。
- 修复应用模板导入后跳转目标字段配置未保存的问题。
- 修复应用模板导入未完成数据源或数据集匹配时返回“系统内部错误”的问题，改为返回明确的匹配提示。
- 修复刚导入但未发布的大屏或仪表盘再次导出应用模板时，图表和跳转配置可能缺失的问题。

## 升级说明

全新安装不需要手动执行 `upgrade-sql/` 中的 SQL。

已有 v1.5.8 环境升级到 v1.5.10 时，只需要替换前后端镜像或使用 v1.5.10 应用镜像升级包，不需要新增升级 SQL。

从 v1.5.7 升级到 v1.5.10 时，请先执行：

```text
upgrade-sql/v1.5.7_to_v1.5.8.sql
```

执行升级 SQL 后，再替换 v1.5.10 前后端镜像。生产环境升级前建议完成数据库备份、运行目录备份和关键报表导出。

## 验证范围

本版本发布前执行以下检查：

- 应用模板内部跳转导入保存单元测试；
- `.DET2`、`.DET2APP` 本地导入解析单元测试；
- 菜单语言包完整性单元测试；
- 工作台菜单显示检查，确认页面不再显示 `i18n_menu.*`；
- 应用模板数据源映射、数据集映射、内部跳转导出和保存验证；
- 刚导入未发布资源的应用模板导出验证；
- 后端编译和单元测试。
