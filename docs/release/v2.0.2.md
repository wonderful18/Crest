# Crest v2.0.2 发布说明

发布日期：2026-06-25

Crest v2.0.2 是 2.0 系列维护版本，重点完成调度元数据表命名统一，并补齐上一版仍可看出两种风格的表名和字段名。

## 发布附件

```text
crest-offline-v2.0.2-linux-amd64.tar.gz
crest-offline-v2.0.2-linux-arm64.tar.gz
crest-app-images-v2.0.2-linux-amd64.tar.gz
crest-app-images-v2.0.2-linux-arm64.tar.gz
crest-source-v2.0.2.tar.gz
crest-v2.0.2-checksums.txt
crest-app-images-v2.0.2-checksums.txt
```

## 镜像

```text
ghcr.io/sevoniva/crest-service:v2.0.2
ghcr.io/sevoniva/crest-web:v2.0.2
```

## 主要变化

- 调度元数据表统一为 `core_schedule_*` 命名。
- 模板分类关系表改为 `core_template_category_relation`。
- 导出下载任务表改为 `core_export_download_task`。
- 数据集和数据源中的调度触发实例列改为 `scheduler_fire_instance_id`。
- Quartz JDBC JobStore 使用统一表名前缀时，运行 SQL 会映射到 Crest 物理表名。

## 升级说明

升级前必须完成以下准备：

- 备份 Crest 系统库；
- 备份运行目录和 `.env`；
- 确认当前系统库类型：MySQL、OceanBase MySQL 或 OceanBase Oracle；
- 确认所有 Crest 服务已停止或处于维护窗口。

全新安装不需要手工执行 `upgrade-sql/`。

从 v2.0.1 升级到 v2.0.2 时，按系统库类型执行以下脚本。

MySQL 系统库：

```text
upgrade-sql/v2.0.1_to_v2.0.2_metadata_names_mysql.sql
```

OceanBase MySQL 系统库：

```text
upgrade-sql/v2.0.1_to_v2.0.2_metadata_names_ob_mysql.sql
```

OceanBase Oracle 系统库：

```text
upgrade-sql/v2.0.1_to_v2.0.2_metadata_names_ob_oracle.sql
```

从 v2.0.0 升级到 v2.0.2 时，先执行 v2.0.1 发布说明中的两个升级脚本，再执行上面的 v2.0.2 脚本。从 v1.5.x 升级时，先按 v2.0.0 发布说明完成主版本迁移，再按顺序执行 v2.0.1 和 v2.0.2 脚本。

## 验证范围

- 前端关系图边类型回归；
- 离线包、应用镜像包和 Kubernetes 交付物版本一致性校验。
