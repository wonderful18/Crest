# Crest v1.5.11-bgfix.2 发布说明

发布日期：2026-06-24

Crest v1.5.11-bgfix.2 是基于 v1.5.11 维护线发布的背景图片和静态资源访问补丁版本，修复数据大屏、表单组件、查询组件、标题组件以及图片类组件配置上传图片后展示不稳定的问题。本版本没有新增数据库结构、系统参数或初始化数据变更。

## 修复内容

- 修复数据大屏画布上传背景图片后，预览和展示页面未稳定渲染背景图的问题。
- 修复表单组件、查询组件和通用组件配置外部背景图片后，背景图可能被组件内部样式覆盖的问题。
- 调整标题类组件背景图样式生成方式，避免资源路径包含空格等字符时出现 CSS 解析不稳定。
- 修复前端 Nginx 静态资源后缀规则优先匹配 `/api/v1/static-resource/` 图片请求，导致上传图片、媒体资源和图片类插件资源访问 404 的问题。

## 升级说明

全新安装不需要手动执行 `upgrade-sql/` 中的 SQL。

已有 v1.5.11 环境升级到 v1.5.11-bgfix.2 时，只需要替换前后端应用镜像，不需要新增升级 SQL。默认运行目录为 `/opt/crest`；如果安装时修改过 `CREST_BASE`，请进入实际运行目录。

```bash
cd /opt/crest
cp .env ".env.bak.$(date +%Y%m%d%H%M%S)"

if grep -q '^CREST_BACKEND_IMAGE=' .env; then
  sed -i.bak 's#^CREST_BACKEND_IMAGE=.*#CREST_BACKEND_IMAGE=ghcr.io/sevoniva/crest-service:v1.5.11-bgfix.2#' .env
else
  printf '\nCREST_BACKEND_IMAGE=ghcr.io/sevoniva/crest-service:v1.5.11-bgfix.2\n' >> .env
fi

if grep -q '^CREST_FRONTEND_IMAGE=' .env; then
  sed -i.bak 's#^CREST_FRONTEND_IMAGE=.*#CREST_FRONTEND_IMAGE=ghcr.io/sevoniva/crest-web:v1.5.11-bgfix.2#' .env
else
  printf '\nCREST_FRONTEND_IMAGE=ghcr.io/sevoniva/crest-web:v1.5.11-bgfix.2\n' >> .env
fi

docker-compose up -d --no-deps crest-service crest
```

生产环境升级前建议完成元数据库、运行目录和关键资源配置备份。
