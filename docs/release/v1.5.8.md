# Crest v1.5.8 发布说明

发布日期：2026-06-12

Crest v1.5.8 是 v1.5 系列的数据资产和缓存管理版本。本版本新增数据资产中心、缓存任务中心，完善数据集缓存状态、任务刷新、用户密码维护和数据准备表格样式。已有 v1.5.x 环境升级时请先备份元数据库和运行目录，并执行 `upgrade-sql/v1.5.7_to_v1.5.8.sql`。

## 离线包

`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。启用 `INCLUDE_OBSERVABILITY_IMAGES=true` 制作的离线包还会包含 Prometheus 和 Grafana 镜像，适合完全无公网环境。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有内网环境只需要替换前后端应用服务时，可使用该包降低传输体积。

## 新增和优化

- 新增数据资产中心，统一查看数据源、数据表、数据集、仪表盘、大屏和分享资源，支持负责人、说明、标签、更新时间、使用次数和上下游影响信息。
- 数据集支持治理状态：已认证、推荐使用、已废弃。已废弃与已认证、推荐使用互斥，避免废弃资产继续被推荐。
- 新增缓存任务中心，集中展示数据集缓存任务、最近执行状态、任务耗时、失败原因和手动更新入口。
- 数据集缓存设置页优化未保存配置、增量不可用、立即更新和定时更新的状态提示。
- 缓存任务点击“立即更新”后自动轮询任务状态，短暂刷新失败会重试。
- 数据资产页、数据集页、数据源页和详情页表格统一使用 `crest-data-table` 样式。
- 数据门户和大屏、仪表盘展示页不向普通访问用户展示缓存技术状态；缓存状态集中在管理端查看。
- 用户管理支持新建或编辑本地账号时设置密码，重置本地密码后返回本次生成的新密码。
- 前端构建产物文件名包含版本号和内容 hash，降低升级后浏览器缓存旧资源的概率。

## 修复内容

- 修复数据资产筛选在部分资产类型下报错的问题。
- 修复非管理员但具备资产维护权限时无法保存资产负责人、治理状态和资产说明的问题。
- 修复数据资产 SQL 按固定组织读取资源，导致管理员也可能无法编辑部分资产的问题。
- 修复数据资产详情页多个 tab 风格与列表页不一致的问题。
- 修复缓存任务轮询遇到短暂接口错误后过早停止的问题。

## 升级说明

全新安装不需要手动执行 `upgrade-sql/` 中的 SQL。

已有 v1.5.7 环境升级到 v1.5.8 时，请先备份元数据库和运行目录，再执行：

```text
upgrade-sql/v1.5.7_to_v1.5.8.sql
```

从 v1.5.4 升级到 v1.5.8 时，请按顺序执行：

```text
upgrade-sql/v1.5.4_to_v1.5.5.sql
upgrade-sql/v1.5.7_to_v1.5.8.sql
```

执行升级 SQL 后，再替换 v1.5.8 前后端镜像。生产环境升级前建议完成数据库备份、运行目录备份和关键报表导出。
