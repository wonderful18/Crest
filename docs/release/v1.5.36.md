# v1.5.36 发布说明

v1.5.36 是 v1.5.35 之后的修复与增强版本。修复明细表「单元格分组」合并文本的换行和居中不生效问题,并补齐该功能的全套样式配置面板;同时为「投产窗口日历」的日期弹出框(popup)新增可视化样式配置,并支持待定版/紧急版圆点标记。**本版本没有新增数据库结构,无需执行升级 SQL。**

## 修复

### 单元格分组合并文本「换行」和「居中」不生效

- 在「单元格分组」的合并文本样式面板里把对齐设为居中、勾选换行后,合并单元格里的文字仍靠左、长文本不换行被截断。
- 根因:S2 v2 的 `MergedCell` 其 `meta` 只是左上角被合并 cell 的 meta,`getBBoxByType` 取到的宽高坐标都只是单格范围,导致文本换行宽度、对齐基准都只落在第一格内;同时 `getTextStyle` 设的是 `wordBreak`/`whiteSpace`,而 G-lite 2.7.0 的 Text 换行由 `wordWrap`(布尔) + `wordWrapWidth`(数值) + `maxLines` 驱动,`wordBreak`/`whiteSpace` 不在其 `PARSED_STYLE_LIST` 内、无效。
- 修复:`CustomMergedCell` 新增 `getMergedContentBox()` 遍历 `this.cells` 求并集后扣除 border+padding 得到合并后真实可用区域;重写 `getMaxTextWidth()` 基于合并宽度、`getTextPosition()` 基于合并矩形按 `textAlign` 定位;`getTextStyle()` 的换行改设 `wordWrap`/`maxLines`(按合并高度自适应行数),与表头自适应行高口径一致。自动合并(`mergeCells`)走同一 `CustomMergedCell` 路径,一并受益。

## 增强

### 单元格分组合并文本样式可配置

- 为「单元格分组」(明细表样式 → 单元格分组)新增合并文本样式配置面板:颜色、字号、加粗、对齐(left/center/right)、换行均可可视化调整,所有分组规则共用一套全局样式。
- 配置存于 `customAttr.tableCell` 的 `cellGroupTextColor`/`cellGroupTextFontSize`/`cellGroupTextIsBolder`/`cellGroupTextAlign`/`cellGroupTextWrap` 字段(`TableCellSelector.vue` 面板、`chart-attr.d.ts` 类型、`chart.ts` 默认值);`common_table.ts` 的 `configCellGroups` 在 `mergedCell` 回调里注入 `meta.cellGroupTextStyle`,由 `CustomMergedCell.getTextStyle` 覆盖 S2 默认 `dataCell.text`。

### 投产窗口日历弹出框(popup)样式可配置

- 「投产窗口日历」点击日期弹出的明细框,其日期标题、版本类型标签、投产内容三段文字的颜色/字号/加粗/对齐/换行均可在右侧面板(图表编辑 → 样式 → 投产窗口日历)可视化调整。
- 新增「待定版」「紧急版」圆点标记:日历单元格内按数据状态显示 `pendingDotColor`/`urgentDotColor` 圆点,并在弹出框版本类型标签旁联动显示。
- 配置存于 `customAttr.deployCalendar` 的 `titlePop*`/`typePop*`/`contentPop*`/`pendingDotColor`/`urgentDotColor` 字段;`zh-CN.ts` 补齐对应文案。

## 技术说明

- 单元格分组样式:`common_table.ts` 的 `configCellGroups` 在 `mergedCell` 回调里通过闭包 `Map` 注入自定义文本与 `cellGroupTextStyle`;`CustomMergedCell` 重写 `getMergedContentBox`/`getMaxTextWidth`/`getTextPosition`/`getTextStyle` 使合并后整体矩形驱动换行与对齐。
- 日历弹窗样式:`DeployCalendarStyleSelector.vue` 扩展配置项;`Component.vue` 的 popup 模板改为内联 `:style`(读取 `state.style`)驱动,换行通过 `pop-nowrap` class 与 `whiteSpace` 控制。
- 兼容老数据:`cellGroupTextStyle` 注入对无 `cellGroups` 的老图表无影响(走自动合并或不合并路径);日历样式字段缺失时由 `setupDefaultOptions` 的 `defaultsDeep` 兜底。
