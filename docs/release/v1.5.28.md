# v1.5.28 发布说明

v1.5.28 是 v1.5.27 之后的修复与功能改进版本。重构数据集「顺序调整」页签为 4 列布局并补齐拖拽,改进饼图/玫瑰图/柱状图标签防重叠与偏移,调整明细表合并单元格比较规则,并在仪表板隐藏明细导出按钮。**本版本没有新增数据库结构,无需执行升级 SQL。**

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.28` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.28` |

## 修复

### 数据集「顺序调整」页签被批量管理表格占用

- 「顺序调整」页签此前同时显示带复选框的批量管理大表格(`batch-area`),盖住了真正的顺序列表,导致看不到 4 列顺序调整界面。
- 修复:`batch-area` 显示条件由 `tabActive !== 'preview'`(manage + order 都显示)收窄为 `tabActive === 'manage'`(仅在批量管理页签显示)。顺序调整页签现只显示顺序列表。`dataset/form/index.vue`。

### 拖拽手柄图标不渲染

- 顺序列表操作列的拖拽手柄原用 `<drag class="svg-icon" />`,但 `drag` 未作为组件导入(仅导入了 svg 资源 `dragSvg`),导致图标不显示、无法拖拽排序。
- 修复:改为 `<Icon name="drag"><dragSvg class="svg-icon" /></Icon>`,与文件内其它图标(如 `icon_left_outlined`)的导入/用法一致。`dataset/form/index.vue`。

### en-US / 繁体中文缺失顺序页签多语言

- `en-US.ts`、`tw.ts` 此前缺失 `field_order`、`field_order_tip`、`moveUp`、`moveDown`,导致这两个语言下整个顺序页签显示原始 key。
- 修复:补齐上述 key,并新增 `dim_quota_type`(维度/指标)、`drag_sort`(拖拽排序)。四个 locale 文件均已对齐。

## 新增

### 顺序调整页签 4 列布局

- 顺序调整页签重构为 4 列:**字段名称 ｜ 物理字段名 ｜ 维度/指标 ｜ 操作(上移、下移、拖拽)**。
- 原拖拽手柄为独立列(导致 5 列),现并入「操作」列与上移/下移按钮并排;表头第 3 列由「物理字段类型」改为「维度/指标」标签。
- 维度/指标以彩色标签展示,拖拽支持维度与指标混合排序。

### 饼图/玫瑰图/柱状图标签防重叠与偏移

- 饼图、玫瑰图新增「标签防重叠」开关(`labelAntiOverlap`),默认开启:外标签开启 `hide-overlap`,全量显示时约束在画布内(`limit-in-plot`)。`pie.ts`、`rose.ts`。
- 新增「标签偏移」配置(`labelOffset`)。`LabelSelector.vue`。
- 抽取按汇总方式(求和/平均/计数/最大/最小)计算总数的通用函数 `calcTotalValue`,柱状图与饼图共用。`bar/common.ts`、`pie.ts`。

## 调整

### 明细表合并单元格改回严格相等

- v1.5.27 将合并单元格比较改为大小写不敏感(`Pos系统/POS系统` 合并为一行)。本版改回严格相等比较,`POS系统` 与 `pos系统` 不再合并。`tableMergeCells.mjs`。

### 仪表板隐藏明细导出按钮

- 放大查看视图(`UserViewEnlarge`)在仪表板(`dvInfo.type === 'dashboard'`)下不再显示明细导出按钮,避免无权限/无意义的导出入口。`UserViewEnlarge.vue`。

### 后端数据查询修复

- `TableInfoHandler`、`ChartDataServer`、`CalciteProvider`、`Provider` 跨源与数据查询相关修复。

## 验证

- 数据集「顺序调整」页签显示 4 列,拖拽手柄可见可拖拽,上移/下移按钮可用。
- 切换到「批量管理」页签仍显示带复选框的维度/指标管理表格。
- 饼图开启标签防重叠后,重叠外标签自动隐藏;关闭后全量显示且约束在画布内。
- 明细表 `POS系统` 与 `pos系统` 相邻不再合并为同一行。
- 仪表板放大查看不显示明细导出按钮。

## 安装说明

- 默认镜像为 `ghcr.io/sevoniva/crest-service:v1.5.28` 和 `ghcr.io/sevoniva/crest-web:v1.5.28`。
