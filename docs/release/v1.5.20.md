# v1.5.20 发布说明

v1.5.20 是 v1.5.19 之后的缺陷修复版本，针对背景图上传、标题备注标识、iframe 嵌入导出按钮、导出原始明细多列等问题进行修复。本版本没有新增数据库结构，无需执行升级 SQL。

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.20` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.20` |

## 修复明细

### 背景图上传不生效

- 组件/画布上传背景图后仅设置 `outerImage`，未启用 `backgroundImageEnable` 与 `backgroundType`，导致背景样式不生成。`applyUploadedBackground` 现在上传后自动启用背景并设置 `backgroundType='outerImage'`，上传即可见。

### 标题备注 i 标识默认显示

- 图表标题的备注（remark）i 标识默认不显示，用户需手动开启。`DEFAULT_TITLE_STYLE` 与 `DEFAULT_TITLE_STYLE_BASE` 的 `remarkShow` 改为 `true`，新建图表默认显示备注标识。

### iframe 嵌入导出按钮丢失

- 分享链接嵌入 iframe 后，放大/详情弹窗的 header 整体被 `v-if="!isIframe"` 隐藏，导致"导出数据"与"导出原始文件"按钮一并消失。改为：有任意导出权限时即渲染 header，标题在 iframe 下单独隐藏，导出按钮按原有权限与 `excelExportEnabled` 条件正常显示。

### 导出原始明细多出空白汇总列

- 开启汇总的表格在导出原始明细（dataset 模式）时，`setExcelData` 内的 `isSummaryEnabled` 判断未排除 dataset 模式，仍把汇总指标列加进表头，而原始数据未扩展对应列，末尾多出一列空白（列名为汇总指标名）。与外层 `summaryEnabled` 判定及 table-info 合并分支保持一致，dataset 模式下不再追加汇总列。

## 验证

- 前端 `vue-tsc` 类型检查通过；前端单元测试 42 个用例全部通过。
- 后端 `core-backend` 编译通过；`ChartDataServerExportModeTest`（11）与 `ChartDataServerAuxiliaryHeaderTest`（1）共 12 个用例全部通过。

- 从 v1.5.19 升级到 v1.5.20 只需要替换前后端镜像，不需要新增升级 SQL。
