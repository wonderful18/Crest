# v1.5.38

发布日期：2026-08-26

## Bug 修复

### 投产日历 DATE 类型字段圆点不显示
生产环境使用 DATE 类型投产日期字段时，有数据的日期不显示圆点。根因是 `parseDate` 函数对后端返回的日期值解析不当：

- **ISO 格式不匹配**：后端可能返回 `2026-07-03T00:00:00.000Z` 格式，旧正则匹配不到（无 `T` 分隔符处理），走兜底 `new Date(isoString)` 有时区偏移风险
- **Date 对象时区偏移**：后端返回 Date 对象时直接 `return raw`，`getDate()` 在跨时区环境下可能返回相邻日期
- **兜底逻辑含时区**：旧兜底 `return dt`（`new Date(s)` 的结果）也带时区信息

修复 `parseDate` 三处：
1. Date 对象：取本地年月日重构纯日期 `new Date(raw.getFullYear(), raw.getMonth(), raw.getDate())`
2. 新增 ISO 格式正则 `/^(\d{4})-(\d{2})-(\d{2})T/`，从字符串字面提取年月日，不依赖时区转换
3. 兜底逻辑：取本地年月日重构，所有路径都返回纯本地日期，彻底消除时区偏移
