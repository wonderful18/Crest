# Crest v2.1.1 发布说明

发布日期：2026-07-04

## 版本信息

- Tag：`v2.1.1`
- 基线版本：`v2.1.0`

Crest v2.1.1 是 2.1 系列的补丁版本，重点修复报表查询、数据大屏分享、明细表排序、导出一致性和会话安全相关问题。本版本不包含数据库结构或初始化数据变更。

## 发布附件

本版本提供以下交付物：

- 完整离线安装包，包含应用服务、前端、数据库、Redis 和可观测性组件镜像；
- 应用镜像升级包，包含 Crest 后端服务和前端 Web 镜像；
- 源码包；
- SHA-256 校验文件。

## 修复内容

- 修复时间范围查询组件在“本周”等动态时间条件下计算范围不准确的问题。
- 修复 Oracle 和 OceanBase Oracle 数据源在时间字段过滤场景下生成 SQL 不兼容的问题。
- 修复数据大屏公共分享首次打开时，富文本、查询组件默认条件和图表数据可能不一致的问题。
- 修复查询组件编辑时字段反显、字段映射和已选数据集字段可能丢失的问题。
- 修复明细表计算字段自定义排序不生效的问题。
- 修复数据集导出在部分筛选和排序场景下与页面结果不一致的问题。
- 修复明细表表头排序点击后可能出现异常浮层且排序未生效的问题。
- 修复可视化编辑器中部分组件配置触发的前端运行告警。

## 安全加固

- 收紧登录回调令牌有效期，降低旧令牌长期可用的风险。
- 增加富文本分享页静态渲染清理，保留基础格式并移除可执行内容。
- 补充加密工具、会话回调、分享页富文本、导出和图表排序相关回归测试。

## 升级说明

从 v2.1.0 升级到 v2.1.1 不需要执行新增 SQL。已有 v2.1.0 环境只需要替换前后端镜像，或使用 v2.1.1 应用镜像升级包完成升级。

升级前建议完成以下准备：

- 备份 Crest 系统库；
- 备份运行目录、上传资源和 `.env`；
- 确认所有 Crest 服务已停止或处于维护窗口；
- 先在测试环境完成同版本、同数据库类型、同数据规模的升级演练。

## 升级后校验

升级完成并启动 v2.1.1 服务后，至少检查以下内容：

- 能够使用原有管理员账号登录；
- 原有数据源、数据集、图表、大屏、模板和分享链接可访问；
- 时间范围查询、查询组件编辑、明细表排序、数据集导出和公共分享页面工作正常；
- “关于系统”入口可以正常展示前后端版本信息；
- 后端日志没有新增异常堆栈；
- 浏览器控制台没有新增错误或告警。

## 回滚原则

升级前必须保留系统库备份、运行目录备份和当前版本镜像。若升级后核心功能不可用，应停止 v2.1.1 服务，恢复升级前系统库和运行目录，再启动原版本服务。
