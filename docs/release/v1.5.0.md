# Crest v1.5.0 发布说明

发布日期：2026-06-01

Crest v1.5.0 是面向全新部署的发布基线，包含当前产品主链路、内置演示资源、平台管理、单点登录、审计日志、服务治理命名和国产密码套件适配。

本次按发布策略跳过中间小版本编号。v1.5.0 不支持从早期开发版本直接执行 Flyway 原地升级。已有环境迁移到本版本时，请先导出业务资源，部署新的 v1.5.0 环境，再导入资源。

## 镜像

发布镜像：

```text

ghcr.io/sevoniva/crest:main
```

支持架构：

```text
linux/amd64

```

## 数据库基线

v1.5.0 只保留两份公开 Flyway 脚本：

| 脚本 | 用途 |
| --- | --- |
| `V1.5.0.1__initial_schema.sql` | 创建元数据库表结构、默认管理员、菜单、系统参数、平台管理、单点登录、审计日志、国产密码套件配置和内置驱动 |
| `V1.5.0.2__demo_resources.sql` | 创建零售经营演示库，以及研发效能主题数据、指标视图、图表、仪表盘和数据大屏 |

这两份脚本只面向新元数据库初始化。

## 主要变化

- 增加字段级数据血缘，覆盖数据源表、物理字段、数据集字段、图表、仪表盘和数据大屏。
- 内置零售经营演示资源和研发效能分析资源。
- 增加 OceanBase Oracle 模式数据源，基于 OceanBase Connector/J。
- 完善平台管理，覆盖用户、角色、权限、单点登录、审计日志、系统参数、站点设置和字体管理。
- 单点登录支持 OIDC / OAuth2 授权码模式，并按系统配置控制登录页入口。
- 国产密码套件模式由配置文件开关控制。
- 服务治理命名统一到 Crest 当前口径，覆盖接口、表结构、模块名和公开文档。
- 提供单机 Docker 安装、Kubernetes 部署和双架构离线部署包。

## 安装注意事项

- 请使用新的元数据库安装 v1.5.0。
- 生产环境必须设置高强度 `CREST_INITIAL_PASSWORD`、`CREST_DB_PASSWORD`、`CREST_AES_KEY` 和 `CREST_AES_IV`。
- 只有在环境明确要求 SM2 / SM3 / SM4 时，才启用 `CREST_CRYPTO_MODE=sm-suite`，并配置 `CREST_SM4_KEY`。
- 将 `/opt/crest` 或实际安装目录纳入备份。
- 生产环境建议启用 HTTPS，并设置明确的 `CREST_ORIGIN_LIST`。
