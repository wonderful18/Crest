# Crest v1.5.15 发布说明

发布日期：2026-07-04

Crest v1.5.15 是 v1.5.14 之后的 1.5 LTS 稳定补丁版本，修复大屏发布、模板导入后静态资源、背景图片保存和自定义国际化资源初始化相关问题。本版本没有新增数据库结构，无需执行升级 SQL。

```text
crest-offline-v1.5.15-linux-arm64.tar.gz

crest-app-images-v1.5.15-linux-arm64.tar.gz

crest-v1.5.15-checksums.txt
```

GitHub Release 页面会自动提供 `Source code (zip)` 和 `Source code (tar.gz)`。`crest-source-v1.5.15.tar.gz` 是发布流程额外生成的命名源码包，便于归档和交付。


支持架构：


`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 与 v1.5.14 的主要差异

### 大屏发布

- 修复大屏发布时提示"资源不存在"的问题。发布流程在同一事务内会先删除 `bi_visualization` 主表记录，再从 `bi_visualization_snapshot` 镜像表恢复主表。v1.5.14 的权限校验只读取主表，导致发布过程中的恢复步骤误判资源不存在。v1.5.15 将恢复权限校验调整为主表优先、镜像表兜底，既保留创建者权限校验，也兼容发布事务中的恢复流程。
- 修复大屏保存发布状态时未带图表类型可能导致权限资源类型被错误写回的问题，避免后续发布、恢复或资源访问出现不一致。

### 模板与静态资源

- 修复模板导出时未完整收集画布、组件、组合、Tab 和嵌套配置中的静态资源地址，导致模板导入到其他环境后背景图、媒体图片或其他静态资源缺失的问题。
- 修复上传背景图片后保存不稳定的问题。上传完成后会以服务端返回的文件地址刷新组件文件列表，避免取消选择或空回调覆盖已上传图片。
- 修复后端静态资源访问目录与上传保存目录不一致的问题。`/api/v1/static-resource/**` 现在使用与上传、模板导入相同的 `crest.path.static-resource` 目录。

### 国际化资源

- 修复未配置自定义前端国际化资源目录时，页面初始化请求 `/sys-parameter/i18n-options` 可能提示"国际化资源目录无效"的问题。自定义语言包目录不存在时返回空集合，不影响系统默认语言。
- 自定义前端国际化资源静态映射支持 `crest.path.i18n.front` 配置，默认路径保持 `/opt/crest/data/i18n/front`。

## 兼容性说明

- 本版本没有新增数据库表、字段或升级 SQL。
- 大屏发布、取消发布、恢复到已发布状态的行为与 v1.5.14 之前一致。
- v1.5.14 的安全加固在其他路径上的权限校验保持不变，仅修正发布恢复事务中主表短暂不存在的场景。
- 现有环境无需新增配置。只有需要调整自定义前端语言包目录时，才需要设置 `CREST_PATH_I18N_FRONT` 或对应 Spring 配置项。

## 验证范围

- 后端定向测试：覆盖大屏发布恢复、图表类型保持、自定义国际化目录缺失和自定义语言包识别。
- 前端定向测试：覆盖静态资源地址收集、背景图片上传状态和模板导入默认值。
- 类型检查：执行前端 TypeScript 检查。
- 发布流程验证：大屏从已保存未发布状态发布为已发布，不再提示"资源不存在"，主表数据由镜像表正确恢复。
- 背景资源验证：上传背景图片后保存、刷新和预览均能加载 `/api/v1/static-resource/**` 资源。
- 跨环境导入验证：大屏模板导入后，背景图和静态资源地址随模板一并迁移，发布操作正常完成。
- 初始化验证：未配置自定义前端国际化资源时，页面初始化不再出现"国际化资源目录无效"报错。
