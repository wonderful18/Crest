# v1.5.31 发布说明

v1.5.31 是 v1.5.30 之后的修复版本。修复明细表带查询条件后结果剩 1 页时不显示分页数量的问题。**本版本没有新增数据库结构,无需执行升级 SQL。**

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.31` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.31` |

## 修复

### 明细表带查询条件后不显示分页数量

- 明细表(component type S2)带查询条件后,结果只剩 1 页(totalItems ≤ pageSize)时分页栏整块不渲染,"共 X 条"总数也消失。
- 根因:`ChartComponentS2.vue` 的 `setupPage` 分页栏显示条件为 `totalItems > pageSize`,查询后单页不满足该条件。
- 修复:条件改为 `totalItems > 0`,只要结果数 > 0 即显示分页栏,单页时 `el-pagination` 的 prev/next 自动 disabled,不影响交互。
