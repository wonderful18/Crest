# Crest v1.5.1 发布说明

发布日期：2026-06-01

Crest v1.5.1 是 v1.5 系列维护发布，面向新的私有化部署环境。此版本调整了内置演示资源的初始化方式，完善单机和 Kubernetes 部署说明，并整理 API 文档页与公开文档中的产品表述。

v1.5.1 仍建议使用空的元数据库安装。已有早期开发环境迁移到本版本时，请先备份元数据库和运行目录，导出业务资源，再在新环境中导入。

## 镜像

```text

```

## 主要变化

- 内置演示资源从核心数据库迁移目录中拆出，通过 `CREST_LOAD_DEMO` 和 `CREST_FLYWAY_LOCATIONS` 控制是否初始化。
- 单机安装包默认加载演示资源；生产环境如不需要示例数据，可在安装前设置 `CREST_LOAD_DEMO=false`。
- 新增 `cleanup-demo-data.sh` 和 `cleanup-demo-data.sql`，用于清理已加载的固定演示数据源、数据集、图表、大屏和 `crest_demo_retail` 演示库。
- Kubernetes 清单增加演示资源开关说明，支持部署纯净环境。
- API 文档页更新为 Crest OpenAPI，接口分组调整为仪表盘与数据大屏、图表、数据集、数据源、数据血缘、导出中心、系统设置、基础能力和权限管理。
- 安装文档、Kubernetes 文档、开发文档和数据血缘文档同步更新，明确核心初始化和演示资源的边界。
- 安装和运维脚本改为安全读取运行目录 `.env`，避免 JDBC 参数中的 `&` 在 shell 中被截断。
- 演示资源脚本不再写死元数据库名，可在自定义 `CREST_DB_NAME` 的新环境中初始化。

## 安装注意事项

- 默认安装会加载零售经营和研发效能演示资源。
- 生产环境不需要示例数据时，安装前设置：

```bash
CREST_LOAD_DEMO=false
```

- 已加载演示资源的单机环境可执行：

```bash
bash cleanup-demo-data.sh --yes
```

- Kubernetes 环境清理演示资源前，先将 `CREST_LOAD_DEMO` 设为 `false`，将 `CREST_FLYWAY_LOCATIONS` 设为 `classpath:db/migration`，重启应用后再执行清理 SQL。
- 生产环境必须设置高强度 `CREST_INITIAL_PASSWORD`、`CREST_DB_PASSWORD`、`CREST_AES_KEY` 和 `CREST_AES_IV`。
- 只有在环境明确要求 SM2 / SM3 / SM4 时，才启用 `CREST_CRYPTO_MODE=sm-suite`，并配置 `CREST_SM4_KEY`。
