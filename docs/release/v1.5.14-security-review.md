# Crest v1.5.14 安全处置说明

本文记录 v1.5.14 安全热修对 SAST/SCA 报告的处置范围和验证结果，供发布前审查使用。原始报告数量、类别和组件归口见 [v1.5.14-security-report-ledger.md](./v1.5.14-security-report-ledger.md)。

## 处置范围

- 路径遍历：收紧文件名、目录解析、静态资源、字体、导出文件、模板和数据源文件访问边界。
- SQL 注入：统一数据源 SQL 单语句和只读校验，补充字符串、注释和字段引用场景测试。
- XSS 与跳转：修复富文本解码、字段值写入、图表提示文本、样式写入、跳转地址、登录回跳、登出地址和跨窗口通信目标来源处理。
- 权限与绑定：补充可视化、图表、联动、外部参数、模板、用户、资产、血缘、分享票据、收藏、数据集字段和 SQL 日志接口的权限或参数边界。
- 上传与资源注入：限制用户导入、字体上传、远程文件、SSRF URL、SSO 端点和响应头内容。
- 信息泄露：非预期异常返回统一为通用提示；业务异常返回前过滤 SQL、Java 类名、堆栈和路径类内部信息。
- 密码与凭据：移除兼容登录配置的固定默认密码，未显式配置时生成随机值并写入本地兼容配置；移除管理端默认密码查询接口，新建本地用户后不再回显默认密码。
- 加密与随机数：新产生的 AES-CBC 密文改为随机 IV，并附加 HMAC 完整性校验；分享密码、无密码分享链接签名密钥和业务临时标识改用 Web Crypto、服务端密钥派生或后端安全随机能力。
- 依赖漏洞：更新后端和前端存在安全告警的依赖版本，前端构建链路同步修复 dev 依赖审计告警。

## 误报说明

以下报告项经逐项核对，不作为代码缺陷处理：

- i18n 中包含“密码”的翻译文案，例如“原密码错误”，不是明文密码。
- 表单模型中的 `password: ''`、`pwd: ''`、`passwd: ''` 是输入框初始值，不是默认密码或凭据。
- 数据源表单中的“密码”单选项和 SSH 密码输入框是用户交互控件，不写入本地存储、日志或控制台。
- 测试代码中的邮箱、密码、Token、版本号、SQL 异常文本和 Mockito 数据库对象均为单元测试夹具，不进入生产配置，也不持有生产连接资源。
- `1.5.8.1` 等 Flyway 迁移版本号被识别为 IP 地址，实际不是网络地址。
- `basic.`、`refreshView`、`share`、`download` 等字符串是配置键名前缀或事件类型，不是加密密钥。
- `DataPortalServer`、`RelationServer`、`SubstituteUserServer` 等接口的请求体和路径变量已由 Spring 注解绑定，且入口有权限校验、分页限制或只读约束。
- `UserCreator`、`UserGridRequest` 是明确的用户管理 DTO；用户创建密码由后端策略校验并编码保存，角色绑定已补充存在性校验。
- 内置管理员账号名 `admin` 是系统初始化账号标识，不是密码；旧版 MD5 `admin` 哈希判断仅用于识别并迁移历史数据，当前管理员初始密码必须来自 `CREST_INITIAL_PASSWORD` 或系统参数。
- 前端构建期目录扫描仅运行在本地构建脚本中，不处理外部请求输入。
- JSON Schema 中的 `$id`、`$schema` 是规范字段名，不是 URL 配置或密钥。
- CSRF 告警已按认证模型审计关闭：前端业务请求通过 `X-CREST-TOKEN` 显式头认证，后端 CORS 配置为 `allowCredentials(false)`，当前产品不依赖浏览器自动携带的 Cookie 完成登录态认证。
- ClassLoader 和反射告警已按受控扩展边界审计关闭：自定义 JDBC 驱动上传要求管理员权限，驱动文件写入受限目录；运行时驱动类名来自已注册驱动记录并校验数据源类型，反射调用的方法名由服务端固定枚举，不接收前端任意方法名。

## 低危项处置边界

SAST 报告包含 1715 条低危项，主要集中在泛化异常、泛化抛出、Vue 样式作用域、StringBuilder 容量、硬编码展示 URL、冗余空值判断、空 catch、列表标签、空方法和浮点数精度等质量规则。

本次安全热修已处理其中与生产安全边界直接相关的低危项，包括前端生产源码 `console.*` 输出、跨窗口消息目标来源、`target="_blank"` 安全属性、SSRF/URL 边界、路径访问边界、资源释放和异常信息外泄。

补充处置项如下：

- ClickHouse SSL 证书临时文件改为按证书内容哈希生成稳定文件名，限制文件权限，并移除 `deleteOnExit()`。
- SSH 隧道本地端口探测改为绑定 `127.0.0.1` 的 `ServerSocket`，避免用普通 Socket 主动连接探测。
- 分享密码生成改为 Web Crypto 随机数，并使用无偏取模和安全洗牌。
- SVG 解析启用安全处理，禁用 DOCTYPE、外部实体、外部 DTD 和外部 Schema 访问。
- CORS 配置移除通配来源回退，部署时必须显式配置允许的来源。
- 日志工具移除标准错误堆栈输出，统一走现有日志通道。
- `BeanUtils` 移除 `System.err` 输出，类型转换失败仅记录字段和类型，不记录原始值。
- 客户端 IP 获取只接收合法 IPv4/IPv6 字面量，代理头中的非法主机名、脚本片段或控制字符不会写入用户信息或水印内容。
- FTP 远程 Excel 下载改为使用 `FTPClient` 登录下载，不再把用户名和密码拼入 URL。
- SM3 HMAC 密码处理移除 `new String(char[])`，改为从 `char[]` 直接编码并清理中间字节缓冲。
- 兼容登录配置在没有显式密码时生成随机值，不再落盘固定默认密码；已存在配置和值保持兼容。
- 新建本地用户后不再调用默认密码查询接口或在弹窗正文回显默认密码；如需交付本次密码，管理员使用重置密码生成。
- Oracle/OB-Oracle `CURRENT_SCHEMA` 设置增加 schema 标识符转义和长度边界。
- Excel 导出和图表汇总的数值解析增加长度和格式边界，超出边界时按文本写入或跳过聚合。
- Excel 水印时间格式化改为线程安全实现，导出中心、图表直出、模板导出和 Excel/CSV 解析的 Workbook、ExcelReader、Reader、响应流均按生命周期关闭。
- 登录页移除自动聚焦属性，降低前端安全扫描噪音。
- 无参数 SQL 执行分支增加单语句校验，避免绕过参数绑定路径执行多语句。
- PreparedStatement 参数日志不再输出原始值，只保留参数序号和目标类型。
- 公开密钥下发和后端对称加密新密文使用 `aes-cbc-hmac:v1` 格式，包含随机 IV、密文和 HMAC；旧固定 IV AES-CBC 密文只保留解密兼容，不再作为新密文格式生成。
- 无密码分享链接的 token 签名密钥不再使用公开固定默认值；显式配置 `crest.default-link-pwd` 时保持兼容，未配置时优先使用 AES Key 派生，开发环境未配置 AES Key 时使用进程级安全随机密钥。
- 导出中心历史文件存在性检查改为受限目录解析，和下载路径保持一致。
- 富文本组件将数据集字段值和字段占位名称写入 HTML 前统一做实体编码，保留阈值样式但不直接写入原始数据值；编码过程使用字符串映射，不依赖 DOM `innerHTML`。
- 图表点击跳转、组件点击跳转和编辑器自定义跳转增加 URL 协议校验，拒绝 `javascript:`、`data:` 等非 Web 协议。
- 自定义登出地址增加协议和账号密码片段校验，CAS 登出回跳地址使用 URL 编码。
- SSO 动态回调地址生成增加 `X-Forwarded-Proto`、`X-Forwarded-Host` 和 `X-Forwarded-Port` 校验，拒绝控制字符、userinfo、路径片段和非法端口。
- Nginx 源站代理不再使用客户端 `Host` 作为后端 Host；如启用 SSO 公网回调，部署时应将 `server_name` 显式配置为对外域名。WebSocket 端点只转发固定升级头，避免 h2c 升级值进入后端。
- 登录页 redirect 和 SSO redirect 只接受站内路径，拒绝外部协议、协议相对地址、反斜杠和控制字符。
- 图表轴标签 tooltip 改为文本节点写入，字体样式写入使用 CSS 字符串转义，阶段漏斗 SVG 配置颜色进入安全颜色白名单。
- 导出文件写入改为 `FileUtils.resolveUnderDirectory` 解析出的文件对象，和导出下载路径保持同一受限目录策略。
- SVG 静态资源检查统一使用固定 Locale 进行大小写归一化，避免区域设置影响危险标签、属性和脚本片段判断。
- 分享票据创建、更新、删除和必填开关增加分享资源归属校验，普通用户只能维护自己创建的分享，管理员保留全局维护能力。
- 收藏新增和收藏列表查询增加资源读权限校验，避免通过历史收藏记录展示不可访问的可视化资源。
- 数据集 SQL 日志保存、查询和删除增加数据集表归属校验，必须先具备对应数据集访问权限。
- 数据集字段读取、批量字段读取、维度指标读取和图表字段批量删除增加数据集或图表访问校验。
- 图表同数据集判断和图表选项列表增加图表或场景读权限校验。
- GitHub Actions 第三方 Action 均固定到版本对应的提交 SHA，并保留版本注释便于审计。
- 前端依赖增加 `@babel/core 7.29.6`、`@ctrl/tinycolor 4.2.0`、`@eslint/plugin-kit 0.7.2`、`debug 4.4.3`、`fast-uri 4.0.0` 和 `is-arrayish 0.3.4` 版本约束；移除未使用的 stylelint 开发链路，gzip 构建改为本地 Vite 插件，ESLint 升级到 10 并迁移 flat config，消除报告中 `@ctrl/tinycolor 3.6.1`、`chalk`、`supports-color`、`ansi-styles`、`color-convert`、`color-name`、`ansi-regex`、`slice-ansi`、`strip-ansi`、`supports-hyperlinks` 等命中。
- npm 安装策略设置 7 天最小发布时间；pnpm workspace 设置 10080 分钟最小发布时间，降低供应链投毒窗口。

### 低危安全类审计结论

| 报告类别 | 处置结论 | 证据边界 |
| --- | --- | --- |
| 硬编码 URL、硬编码域名 | 已区分配置模板、文档示例和运行时入口；SSO、跳转、SSRF、CORS 来源已增加校验 | 运行时外部 URL 必须经过协议、主机、端口或来源校验 |
| 硬编码加密密钥、明文密码、空密码 | 已移除兼容登录固定默认密码、管理端默认密码查询接口和无密码分享链接固定签名密钥；表单空值、翻译文案、测试夹具不作为凭据 | 生产密码来自环境变量、系统参数或用户输入，并按策略编码保存；无密码分享 token 密钥来自显式配置、AES Key 派生或进程级安全随机值 |
| 弱加密、MD5、RSA PKCS#1 | 新 AES-CBC 密文已升级为随机 IV + HMAC；MD5 和旧 RSA/AES 路径仅保留历史数据、登录协议和文件名摘要兼容 | 不改变存量密文和历史密码识别逻辑；算法整体迁移需另立兼容方案 |
| CSRF | 审计关闭 | 产品使用显式请求头 token；CORS 不允许携带凭据 |
| 不安全随机数 | 已修复分享密码和业务临时标识；动画、图表视觉临时 ID、编辑器 DOM id 保留 | 剩余 `Math.random()` 不参与认证、授权、密码、Token 或密钥生成 |

JSON 响应相关“JavaScript 劫持”告警由全局 `SecurityHeadersConfig` 覆盖，所有后端响应统一设置 `X-Content-Type-Options: nosniff`。

MD5、旧 RSA/AES 路径属于历史数据和接口兼容边界，本次不改变既有密文、签名或存量配置的读写规则。新产生的 AES-CBC 密文已切换为随机 IV + HMAC 格式；后续如需替换 RSA 登录传输协议或彻底移除旧 AES 解密兼容，应单独设计迁移方案并覆盖历史客户端和存量数据兼容测试。

报告中的其他 `Math.random()` 告警用于组件临时 ID、动画时序、图表临时标识或第三方 vendor 抖动逻辑，不参与密码、Token、密钥、会话或权限判断。分享密码生成路径已改为 Web Crypto。

剩余低危质量项不改变认证、授权、SQL、文件、上传、SSO、WebSocket 或依赖安全边界，不作为本次安全补丁阻断项；如需统一治理，应单独建立质量改造分支并按模块回归。
