# v1.5.37

发布日期：2026-08-25

## 新功能

### 投产日历图例动态化
版本类型图例从写死的固定 4 类（周版/月版/待定版/紧急版）改为按数据集里实际出现的版本类型动态显示。
- 图例项随数据动态生成，数据里没有的类型不显示
- 每个类型按出现顺序自动配色，用户可在样式面板逐个覆盖颜色
- 样式面板"类型颜色"区段动态渲染：从图表数据去重出类型列表，每个类型一个颜色选择器
- 空类型值统一显示为"未指定"
- 向后兼容：老图表的 weeklyDotColor 等旧字段保留但不读取，用户重新配色后写入 typeColorMap

## Bug 修复

### 预览/分享态图表不发 data 请求（P0）
v1.5.33 为优化首屏性能，将图表渲染组件（ChartComponentG2Plot/ChartComponentS2）改为 `defineAsyncComponent` 异步加载。这导致预览态/分享态首次加载时，`onMounted` 的 `queryData` 执行时异步组件尚未挂载，`chartComponent` ref 为空，`calcData` 跳过取数逻辑，不发 `/chart-data/data` 请求，图表数据为空。
- 编辑态正常（有用户交互触发的 `calcData-{id}` 事件兜底）
- 投产日历正常（自定义组件，自己调 getData，不依赖 chartComponent ref）
- **修复**：加 `watch(chartComponent)` 监听异步组件首次就绪，补触发一次 `queryData`；`loading.value` + `chartComponentLoaded` 标志位双重防重复
- 保留 v1.5.33 的懒加载性能优化（首屏 preload 3.6MB 不变）
