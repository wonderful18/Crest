# v1.5.35 发布说明

v1.5.35 是 v1.5.34 之后的修复与增强版本。修复「投产窗口日历」在深色画布下月份切换按钮不可见的问题,并为该日历组件补充可视化样式配置面板。**本版本没有新增数据库结构,无需执行升级 SQL。**

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.35` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.35` |

## 修复

### 投产窗口日历月份切换按钮不可见

- 深色画布下,日历右上角的「上一月 / 回到今天 / 下一月」三个导航按钮继承了外层深色文字,导致按钮隐形、无法切换月份。
- 修复:导航按钮颜色跟随标题色(`titleColor`)内联渲染,深色画布下与标题同色可见;浅色画布同样自适应。

## 增强

### 投产窗口日历样式可配置

- 新增「投产窗口日历样式」配置面板(图表编辑 → 样式 → 投产窗口日历):月份标题、日期数字、单元格底色/悬浮底色/投产单元格底色、今日边框、选中边框/底色、周版/月版圆点色、星期表头、图例文字等颜色与字号均可在右侧面板可视化调整。
- 配置存于 `customAttr.deployCalendar`,对应 `ChartDeployCalendarStyle` 类型;`DEFAULT_DEPLOY_CALENDAR_STYLE` 提供深色画布默认值。
- 图表注册接入 `setupDefaultOptions`:新建或切换到日历组件时自动补全样式默认值,兼容 v1.5.34 无 `deployCalendar` 字段的老数据,避免样式缺失导致渲染异常。
- 组件内颜色全部由模板内联 `:style`(读取 `state.style`)驱动,悬浮底色通过根节点 CSS 变量 `--dc-cell-hover` 传入,与现有样式驱动约定一致。

## 技术说明

- 样式配置:`DeployCalendarStyleSelector.vue` 新增选择器组件,挂载于 `ChartStyle.vue`;`deploy-calendar.ts` 的 `properties` 增加 `deploy-calendar-style-selector`,`propertyInner` 同步登记。
- 兼容老数据:`DeployCalendarView.setupDefaultOptions` 用 `defaultsDeep` 合并用户配置与默认值,`Component.vue` 的 `renderChart` 同样 `defaultsDeep` 兜底,双保险保证老图表升级后样式不丢失。
