# Crest v2.1.0 发布说明

发布日期：待定

Crest v2.1.0 是 2.x 系列的功能与安全基线整合版本。本版本在保留 v2 架构的基础上，合入 v1.5.14 中已验证的可视化、报表查询、明细表汇总、模板导入导出和安全加固改进，并补充从 v1.5.14 与 v2.0.3 升级到 v2.1.0 的数据库脚本。

## 新增与增强

- 增强报表明细表汇总能力，支持在表格中配置汇总指标列，并支持求和、平均值、自定义计算结果、显示格式和导出结果。
- 增强时间范围查询，支持只填写开始时间或结束时间，用于查询某个时间之后或某个时间之前的数据。
- 增强查询组件的固定时间配置，支持直接输入日期，减少必须通过日期面板选择的限制。
- 增强大屏背景、表单背景和查询组件背景的图片渲染稳定性。
- 增强大屏公共分享跳转，修复从报表或外部嵌入页面跳转到已公开分享大屏时的访问校验问题。
- 增强大屏模板导入导出流程，提高导入兼容性、文件校验和异常处理稳定性。
- 增强旧版大屏配置兼容性，自动补齐部分历史组件缺失的默认配置。

## 修复内容

- 修复表头排序点击后可能出现异常提示条、排序状态不生效的问题。
- 修复动态日期过滤条件在“今年”等预设值下提交失败的问题。
- 修复汇总表启用汇总配置后，部分场景图表数据无法加载的问题。
- 修复导出明细表时汇总指标列和汇总行不一致的问题。
- 修复大屏公共分享场景下目标图表读取来源不一致导致跳转失败的问题。
- 修复部分模板导入流程中资源树刷新、重复选择同一文件和浏览器弹窗拦截导致的导入体验问题。

## 安全加固

- 移除初始化数据中的公开模板访问密钥默认值。
- 调整公开链接默认密钥策略，避免使用固定公开默认值。
- 升级并对齐 Calcite、Netty、Logback、TinyMCE 等依赖版本。
- 增加初始化数据、分享密钥、嵌入访问令牌、模板资源存储等安全回归测试。
- 增加前端生产依赖审计、OSV 扫描、Semgrep SAST 和 Secret 扫描验证。

## 升级说明

升级前必须完成以下准备：

- 备份 Crest 系统库；
- 备份运行目录和 `.env`；
- 确认当前系统库类型：MySQL、OceanBase MySQL 或 OceanBase Oracle；
- 确认所有 Crest 服务已停止或处于维护窗口；
- 先在测试环境完成同版本、同数据库类型、同数据规模的升级演练。

从 v2.0.3 升级到 v2.1.0 时，按数据库类型执行对应脚本：

- MySQL：`upgrade-sql/v2.0.3_to_v2.1.0_mysql.sql`
- OceanBase MySQL 模式：`upgrade-sql/v2.0.3_to_v2.1.0_ob_mysql.sql`
- OceanBase Oracle 模式：`upgrade-sql/v2.0.3_to_v2.1.0_ob_oracle.sql`

从 v1.5.14 升级到 v2.1.0 时，MySQL 环境执行：

```text
mysql --commands=ON -u<user> -p <crest_database> < upgrade-sql/v1.5.14_to_v2.1.0_mysql.sql
```

已有系统库升级时不要执行 full schema 文件。full schema 文件仅用于新建空系统库。

## 升级后校验

升级完成并启动 v2.1.0 服务后，至少检查以下内容：

- 能够使用原有管理员账号登录；
- 原有数据源、数据集、图表、大屏、模板和分享链接可访问；
- 大屏编辑、预览、查询组件、明细表汇总、模板导入导出和公共分享跳转工作正常；
- 后端日志没有新增异常堆栈；
- 浏览器控制台没有新增错误或告警。

## 回滚原则

升级前必须保留系统库备份、运行目录备份和当前版本镜像。若升级脚本执行失败或升级后核心功能不可用，应停止 v2.1.0 服务，恢复升级前系统库和运行目录，再启动原版本服务。不要在部分执行成功的数据库上重复执行 full schema 或跳过失败步骤继续启动服务。

## 已知限制

- `v1.5.14 -> v2.1.0` 仅提供 MySQL 系统库升级入口。
- OceanBase MySQL 和 OceanBase Oracle 系统库支持 `v2.0.3 -> v2.1.0` 升级与 v2.1.0 新装初始化。
- 从 v1.5.14 升级前，应先确认第三方插件、外部数据源驱动和自定义部署脚本与 v2.x 运行目录和镜像命名兼容。

- 后端定向安全测试、图表汇总测试、模板资源存储测试、公开跳转测试；
- 前端报表查询、动态日期、明细表汇总、表头排序、背景图片和模板导入导出回归测试；
- Semgrep SAST、Secret 扫描、pnpm 生产依赖审计、OSV 前端与后端依赖扫描；
- GitHub Actions Release Guard。
