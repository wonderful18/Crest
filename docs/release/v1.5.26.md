# v1.5.26 发布说明

v1.5.26 是 v1.5.25 之后的功能版本，新增数据集缓存按天自定义时点、明细表合并大小写、数据集字段上下移，并修复导出 Excel 小数显示缺陷。**本版本新增数据库结构，升级需执行升级 SQL（V1.5.9.1）。**

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.26` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.26` |

## 新增

### 数据集缓存按天自定义时点

- 数据集缓存的「按天更新」简单调度此前固定在凌晨 0 点执行，现支持选择 0-23 点的任意时点（如每天早上 8 点）。
- 新增字段 `simple_cron_hour`（int，NULL=0 点，向后兼容），通过 Flyway 迁移 `V1.5.9.1__dataset_sync_task_simple_cron_hour.sql` 添加到 `dataset_sync_task` 表。
- 保存时点后 cron 形如 `0 0 8 1/1 * ? *`（每天 8 点）。旧行无 `simple_cron_hour` 的任务默认 0 点，行为不变。

### 明细表合并单元格大小写不敏感

- 明细表（table-info/table-normal）合并单元格时按大小写不敏感比较，`Pos系统/POS系统/pos系统` 这类仅大小写不同的相邻值合并为一行。
- 合并段中央单元格统一显示大写形式，避免合并后大小写不一。
- 前提：s2 为相邻同值合并，需大小写变体在数据中相邻才合并。

### 数据集字段上下移

- 数据集字段列表支持上移/下移调整顺序，导出 Excel 列按调整后的顺序排列。
- 字段顺序通过 `column_index` 持久化，旧数据（null）排到最后保证兼容。

## 修复

### 导出 Excel 小数显示

- 修复 FLOAT 类型字段导出后值为整数时显示 `0.`（带多余小数点）：FLOAT 整数值现用纯整数格式 `"0"` 写入，显示 `0`/`12`。
- 修复 FLOAT 小数值被误取整为整数（如 `3.14` 显示成 `3`）：FLOAT 非整数值现显式用 `"0.######"` 小数格式写入，保留小数，不再被 formatter 整数格式覆盖。
- `ChartDataServer.setExcelData`（table-info/table-normal 分支 + 其他视图分支）与 `ExportCenterDownLoadManage.setExportCellValue` 两条导出路径均已修复。

### 保存同步任务后时点丢失

- 修复保存数据集同步任务后「按天时点」丢失：前端保存 payload `buildDatasetSyncTaskPayload` 漏传 `simpleCronHour` 字段，导致后端存空。已补传。

## 验证

- 数据集缓存：选按天更新 + 间隔 1 + 时点 8 点，保存后重开表单时点仍为 8 点，DB `simple_cron_hour=8`、`cron='0 0 8 1/1 * ? *'`。
- 明细表合并：含 Pos系统/POS系统/pos系统 相邻值的维度列合并为一行，中央显示 POS系统。
- 字段上下移：调整字段顺序保存后导出 Excel，列顺序与调整后一致。
- 导出 Excel：FLOAT 整数 `12.0`→`12`、`0`→`0`（不再 `0.`）；FLOAT 小数 `3.14`→`3.14`（不再误显示 `3`）。

## 升级说明

- **本次新增数据库结构，从 v1.5.25 升级到 v1.5.26 需要执行升级 SQL**：后端启动时 Flyway 自动应用 `V1.5.9.1`（给 `dataset_sync_task` 表加 `simple_cron_hour` 列）。确保启动用户对该库有 DDL 权限。
- 镜像升级：替换前后端镜像至 `v1.5.26`。

## 兼容性

- 旧行 `simple_cron_hour` 为 NULL 默认 0 点，既有按天任务行为不变。
- 既有字段无 `column_index` 的任务，查询时 null 排到最后，向后兼容。
