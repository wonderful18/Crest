# Crest v1.5.17 发布说明

发布日期：2026-07-09

Crest v1.5.17 是 v1.5.16 之后的 1.5 LTS 补丁版本，修复明细表单元格合并的一个缺陷。本版本没有新增数据库结构，已有环境升级时只需替换前后端镜像，无需执行升级 SQL。

`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 与 v1.5.16 的主要差异

### 明细表单元格合并

- 修复明细表（table-info）单元格合并缺陷：当某列在所有行的值完全相同，但前置维度列的值变化把数据切成了多段时，该列无法合并。典型表现是表格最后一列的值全部相同却显示为多行而不合并。
- 值完全相同的列现在会跨前置列隔断合并整列；值不完全相同的列仍保留原有层级上下文，不连续的相同值不会被跨段合并。

本版本没有数据库结构、系统参数或初始化数据变化，也没有依赖版本调整。

## 升级说明

- 本版本没有新增业务表、字段或系统参数，没有数据库变更。
- 已有 v1.5.16 环境升级到 v1.5.17 时，只需替换前后端镜像，无需执行升级 SQL。
- v1.5.15 或更早 v1.5.x 环境升级时，仍需按历史版本说明依次补齐已发布的升级 SQL，再替换到 v1.5.17 镜像。

## 验证范围

- 单元测试：新增并更新 `tableMergeCells` 单元测试，覆盖全相同列跨隔断合并、不全相同列保留前置上下文、末列被前置不连续列隔断等场景。
- 本地部署验证：在本地 Docker 部署环境验证多列明细表的合并行为，确认值完全相同的列正确合并，不连续的相同值不被跨段合并。
