# Crest v1.5.16 发布说明

发布日期：2026-07-05

Crest v1.5.16 是 v1.5.15 之后的 1.5 LTS 安全补丁版本，重点修复和加固数据导入、文件上传、SQL 生成、跨窗口通信和依赖组件相关风险。本版本没有新增业务表结构，已有环境升级时需要执行 `upgrade-sql/v1.5.15_to_v1.5.16.sql` 补齐血缘菜单权限记录。

```text
ghcr.io/sevoniva/crest-web:v1.5.16
```

支持架构：


`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 与 v1.5.15 的主要差异

### 数据导入与 SQL 安全

- Excel/CSV 数据源导入生成引擎表、字段和视图 SQL 时，统一校验表名、字段名和视图名，并对数据值使用参数绑定。
- 数据源引擎视图创建继续走只读 SQL 策略校验，拒绝多语句和非只读语句。
- 只读 SQL 策略返回规范化后的单语句 SQL，避免后续调用绕过策略处理结果。
- Excel 解析未得到有效工作表时会明确拒绝，不再进入后续空结果处理流程。

### 上传边界

- 用户批量导入限制为管理员操作，并在解析前校验文件名、大小、后缀和内容特征。
- 驱动 JAR 上传会校验 JAR 后缀和 ZIP 内容结构，拒绝伪造文件。
- 静态资源上传会校验图片格式、SVG 安全内容、文件大小、文件名和保存路径。
- 字体、数据源 Excel 和应用模板上传流程补齐大小、文件名、格式和异常清理校验。

### 前端跳转与嵌入通信

- 大屏跳转返回地址会限制为同源地址，避免使用不可信 URL 触发跳转。
- 嵌入和预览场景的 `postMessage` 目标来源统一通过同源或允许来源校验。
- 前端静态资源上传类型与后端校验保持一致。

### 稳定性

- 修复图表动态时间、柱状范围数据和汇总导出中的空值路径。
- 汇总行导出累加器使用明确初始化，避免空值路径被异常数据触发。
- 生成的静态资源、构建产物、第三方编辑器资源和目标目录不再作为业务源码分析对象。

### 依赖

- `logback-core` 升级至 `1.5.33`。
- `mysql-connector-j` 保持为 `8.2.0`。
- `netty-handler` 保持为 `4.2.15.Final`。
- `jackson-databind` 保持为 `2.22.0`，并增加用例确认未启用大小写不敏感属性绑定。
- 前端富文本和颜色处理相关依赖锁定到当前安全版本，并移除旧的本地补丁。

## 升级说明

- 本版本没有新增业务表、字段或系统参数。
- 已有 v1.5.14 或 v1.5.15 环境升级到 v1.5.16 时，请先备份元数据库和运行目录，再执行 `upgrade-sql/v1.5.15_to_v1.5.16.sql`，随后替换前后端镜像。
- v1.5.13 或更早 v1.5.x 环境升级时，仍需按历史版本说明依次补齐已发布的升级 SQL，再执行本版本升级 SQL 并替换到 v1.5.16 镜像。
- 文件上传校验比旧版本更严格，伪造后缀、空文件、超限文件、危险 SVG 和无效办公文档会被拒绝。

## 验证范围

- 安全审计台账：完成本版本范围内安全问题的复核、修复和证据归档。
- 后端安全测试：覆盖 SQL 策略、Excel 字段、Calcite 执行、上传校验、静态资源、可视化权限、字体上传、图表汇总、用户导入和 JSON 反序列化安全默认值。
- 前端安全测试：覆盖同源 URL、静态资源上传、国际化 key、语言策略和汇总列配置。
- 类型检查：执行前端 TypeScript 检查。
- 依赖审计：执行前端生产依赖审计，并核查后端关键依赖树。
- 静态检查：执行源码安全规则检查，未发现新增有效问题。
