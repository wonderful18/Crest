# v1.5.23 发布说明

v1.5.23 是 v1.5.22 之后的缺陷修复版本，修复明细表开启自动换行后整表空白、以及仪表盘分享链接默认加密码后仍要求输入密码的问题。本版本没有新增数据库结构，无需执行升级 SQL。

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.23` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.23` |

## 修复明细

### 明细表开启自动换行后整张表空白

- 明细表勾选「自动换行」后，整张表区域空白、无任何内容，浏览器控制台报 `TypeError`。不勾选时表格显示正常。
- 根因是 `@antv/s2` 升级到 v2 后，自定义换行渲染函数 `drawTextShape` 仍沿用 v1 已移除/变更的 API：
  - `cell.getTextAndIconPosition()` 在 v2 已移除，调用即抛 `TypeError`，导致每个数据单元格的 `drawTextShape` 崩溃、整表渲染中断。
  - `renderText` 在 v2 改为对象签名（`{ group, textShape, style }`），v1 的位置参数签名已不适用。
  - `cell.actualText` / `cell.actualTextWidth` 在 v2 改为只读 getter（从 `textShape` 派生），赋值会抛 `Cannot set property ... which has only a getter`。
  - `cell.getCellArea()` 在 v2 已移除，由 `getBBoxByType()` 取代。
  - `LayoutResult.spreadsheet` 在 v2 已移除，`calculateHeaderHeight` 中 `ev.spreadsheet` 为 `undefined`，导致 `measureTextWidthRoughly` 读取失败。
  - g5.0 的 `Text` 需显式传 `wordWrapWidth` 才能正确度量文本宽度，否则 `getBBox` 宽度返回 1、文本不可见。
  - `getEmptyPlaceholder(this, ...)` 在箭头函数中 `this` 为空，v2 签名要求传 `meta`。
- 修复：逐一替换为 v2 对应 API，补全 `wordWrapWidth` / `maxLines`，只读 getter 改为直接传 `wrapText` 变量。
- 已知遗留：最大行数（`maxLines`）截断在部分场景未完全生效（g5.0 的 `Text` 设 `wordWrapWidth` 后自行按宽度换行，覆盖手动切行结果），后续单独处理。

### 仪表盘分享链接默认加密码后仍要求输入密码

- 仪表盘开启分享时，前端未勾选「密码保护」，但分享链接打开后仍要求输入密码。
- 根因：`autoPwd=true` 表示密钥由系统自动生成（仅用于链接签名），但后端 `pwdValid` / `valid` 未区分此场景，仍走密码校验逻辑；`detail` 接口又把内部密钥返回给前端，导致前端误判密码保护已开启。
- 修复：`ShareManage.pwdValid` / `valid` 在 `autoPwd=true` 时直接放行；`ShareServer.detail` 在 `autoPwd=true` 时将 `pwd` 置空返回，避免前端误判。

## 验证

- 明细表勾选「自动换行」后，表格框架与单元格内容正常显示（修复前整片空白）。浏览器控制台不再有 `getTextAndIconPosition is not a function`、`Cannot set property actualText`、`getCellArea is not a function`、`measureTextWidthRoughly of undefined` 等报错。
- 仪表盘分享链接（未勾选密码保护）打开后不再要求输入密码，直接进入。

## 升级说明

- 从 v1.5.22 升级到 v1.5.23 只需要替换前后端镜像，不需要新增升级 SQL。

## 兼容性

- 仅修改前端明细表自定义渲染逻辑与后端分享校验逻辑，不影响数据结构与其他组件行为。
