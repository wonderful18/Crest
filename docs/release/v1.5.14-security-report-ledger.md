## 许可证报告边界

许可证报告已复核。报告中的高风险许可证主要来自项目自身 GPLv3 许可文件和 README，以及少量第三方组件的 GPL/EPL/LGPL/EDL/BSD 分类。Crest 当前按 GPLv3 发布，发布材料已保留 GPLv3 声明；`jszip` 为 MIT/GPL 双许可证组件，按 MIT 许可选项使用。该报告属于许可证合规审计，不属于本次 SAST/SCA 漏洞修复项；如交付场景要求非 GPL 发行或更严格的第三方许可证策略，需要单独进行法务和依赖替换评审。
