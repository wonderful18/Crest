# Crest v1.5.14 发布说明

发布日期：2026-07-02

Crest v1.5.14 是 v1.5.13 之后的稳定补丁版本，合并安全加固、公共分享内部跳转、查询组件时间范围和表格汇总能力。本版本没有新增数据库结构；初始化数据清理了模板中心访问密钥的默认值，已有 v1.5.x 环境升级时需要执行对应升级 SQL。

## 交付物

```text
crest-offline-v1.5.14-linux-amd64.tar.gz
crest-offline-v1.5.14-linux-arm64.tar.gz
crest-app-images-v1.5.14-linux-amd64.tar.gz
crest-app-images-v1.5.14-linux-arm64.tar.gz
crest-source-v1.5.14.tar.gz
crest-v1.5.14-checksums.txt
crest-app-images-v1.5.14-checksums.txt
```

GitHub Release 页面会自动提供 `Source code (zip)` 和 `Source code (tar.gz)`。`crest-source-v1.5.14.tar.gz` 是发布流程额外生成的命名源码包，便于归档和交付。

## 镜像

```text
ghcr.io/sevoniva/crest-service:v1.5.14
ghcr.io/sevoniva/crest-web:v1.5.14
```

支持架构：

```text
linux/amd64
linux/arm64
```

`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 修复内容

- 修复文件路径、上传文件名、静态资源、字体文件和导出文件写入/下载边界不完整的问题。
- 收紧数据源 SQL 执行校验，拦截多语句和非只读语句，保留字符串、注释和字段引用中的合法分号。
- 修复可视化、图表、联动、外部参数、模板、用户管理、分享票据、收藏、数据集字段和 SQL 日志相关接口的权限与参数校验缺口。
- 修复 WebSocket 握手信任请求参数 `userId` 的问题，改为使用当前登录用户身份。
- 收敛登录回跳、SSO 回跳、代理头生成回调地址、SSRF URL、异常返回、响应头、SVG 静态资源和跨窗口通信边界，避免内部信息或不可信参数外泄。
- 修复富文本字段值、字段占位名称、图表提示文本、字体样式和 SVG 配置写入前的编码/转义边界。
- 修复兼容登录配置固定默认密码、客户端 IP 头未净化、Excel/CSV 解析和导出资源释放不完整的问题。
- 移除管理端默认密码查询接口；新建本地用户后不再回显默认密码，重置密码仍返回本次生成密码，便于管理员交付。
- 修复后端打包前未清理旧前端静态资源的问题，避免历史 chunk 混入交付 JAR。
- 新产生的 AES-CBC 密文改为随机 IV 并附加 HMAC 完整性校验，旧密文保留解密兼容；分享密码、无密码分享链接签名密钥和业务临时标识改用安全随机或服务端密钥派生能力生成。
- 清理模板中心访问密钥的安装默认值；升级脚本只处理仍保持旧默认值的环境，不覆盖用户自定义配置。
- 更新后端依赖 `spring-core`、`spring-ldap-core`、`calcite-core`、`jackson-databind` 和 `netty-handler`，并修复前端生产与构建链路依赖安全告警。
- 固定 GitHub Actions 第三方 Action 到提交 SHA，增加 npm/pnpm 包发布时间等待策略，并收紧 Nginx Host 与 WebSocket 升级头转发。
- Kubernetes 清单移除 ConfigMap 中的敏感占位字段，改由 Secret 和标准环境变量注入，并补齐容器安全上下文、只读根文件系统和资源限制。
- 修复公共分享或嵌入报表中，数据大屏 A 跳转到已公开分享的数据大屏 B 时可能提示 `link token invalid` 的问题。
- 修复时间范围查询只填写单侧时间时，前后端仍按完整区间处理导致无法查询单侧边界数据的问题。
- 修复表格导出汇总行在无维度列时可能用汇总标签覆盖首个指标汇总值的问题。

## 功能改进

- 查询组件时间范围支持只填写开始时间或结束时间，分别用于查询某个时间之后或之前的数据。
- 明细表和普通表的已有列汇总支持求和、平均值、最大值、最小值和自定义公式。
- 明细表支持新增虚拟汇总指标列，明细行显示空值占位，汇总行显示按过滤后全量数据计算的结果，并在预览、分享、嵌入和导出中保持一致。

## 验证范围

- 后端安全定向测试：路径访问、SQL 单语句策略、SSRF、异常信息脱敏、WebSocket 身份、用户角色绑定和接口权限边界。
- 后端导出与 Excel 定向测试：导出任务、导出下载、图表导出模式、Excel 字段解析和资源释放相关路径。
- 报表功能定向测试：公共分享内部跳转 URL 构造、跳转配置 mapper、时间单侧过滤 SQL、导出汇总公式优先级和虚拟汇总指标列。
- 前端验证：类型检查、lint、生产构建、公共跳转构造、表格汇总列和表格汇总高度脚本测试。
- 安全验证：SAST、SCA、Release Guard 和关键依赖版本核查。
- 打包验证：后端复制前端静态资源前清理旧目录，`CoreApplication.jar` 未发现旧默认密码接口和旧文案。
- 交付包验证：应用镜像包和完整离线包均包含 `v1.5.13_to_v1.5.14.sql`，包内 README 写明升级 SQL 执行链路。
- 加密兼容验证：新 AES-CBC-HMAC 密文可正常解密，篡改密文会被拒绝，旧 AES-CBC 密文仍可读取。
- Kubernetes 验证：部署清单可渲染，渲染后的 YAML 可离线解析。

## 升级说明

全新安装不需要手动执行 `upgrade-sql/` 中的 SQL。

从 v1.5.13 升级到 v1.5.14 时，请先执行：

```text
upgrade-sql/v1.5.13_to_v1.5.14.sql
```

从 v1.5.8 升级到 v1.5.14 时，请执行同一个 `upgrade-sql/v1.5.13_to_v1.5.14.sql`，再替换前后端镜像或使用应用镜像升级包。

从 v1.5.7 升级到 v1.5.14 时，请先执行：

```text
upgrade-sql/v1.5.7_to_v1.5.8.sql
upgrade-sql/v1.5.13_to_v1.5.14.sql
```

从 v1.5.4 升级到 v1.5.14 时，请先执行：

```text
upgrade-sql/v1.5.4_to_v1.5.5.sql
upgrade-sql/v1.5.7_to_v1.5.8.sql
upgrade-sql/v1.5.13_to_v1.5.14.sql
```

执行升级 SQL 后，再替换 v1.5.14 前后端镜像。生产环境升级前建议完成元数据库备份、运行目录备份和关键资源导出。
