# Crest v1.5.14 发布说明

发布日期：2026-07-03

Crest v1.5.14 是 v1.5.13 之后的 1.5 LTS 稳定补丁版本，重点覆盖安全加固、公共分享内部跳转、查询条件、表格汇总、模板导入导出、画布组合编排和交付包稳定性。本版本没有新增数据库结构；初始化数据仅清理模板中心访问密钥的旧默认值，已有 v1.5.x 环境升级时需要执行对应升级 SQL。

## 交付物

```text

crest-offline-v1.5.14-linux-arm64.tar.gz

crest-app-images-v1.5.14-linux-arm64.tar.gz
```

GitHub Release 页面会自动提供 `Source code (zip)` 和 `Source code (tar.gz)`。`crest-source-v1.5.14.tar.gz` 是发布流程额外生成的命名源码包，便于归档和交付。

## 镜像

```text

ghcr.io/sevoniva/crest-web:v1.5.14
```

支持架构：

```text
linux/amd64

```

`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 与 v1.5.13 的主要差异

### 安全与平台边界

- 收紧文件路径、上传文件名、静态资源、字体文件和导出文件的访问边界，避免越权读取或写入。
- 收紧数据源 SQL 执行策略，拦截多语句和非只读语句，同时保留字符串、注释和字段引用中的合法分号。
- 补齐可视化、图表、联动、外部参数、模板、用户管理、分享票据、收藏、数据集字段和 SQL 日志相关接口的权限与参数校验。
- WebSocket 握手改为使用当前登录用户身份，不再信任请求参数里的 `userId`。
- 收敛登录回跳、SSO 回跳、代理头回调地址、SSRF URL、异常返回、响应头、SVG 静态资源和跨窗口通信边界。
- 富文本字段值、字段占位名称、图表提示文本、字体样式和 SVG 配置写入前增加编码或转义处理。
- 分享密码、无密码分享链接签名密钥和业务临时标识改为使用安全随机值或服务端密钥派生能力生成。
- 移除管理端默认密码查询接口；新建本地用户后不再回显默认密码，重置密码仍返回本次生成密码，便于管理员交付。
- 清理模板中心访问密钥的安装默认值；升级脚本只处理仍保持旧默认值的环境，不覆盖用户自定义配置。
- 更新存在安全告警的后端和前端依赖，并固定 GitHub Actions 第三方 Action 到提交 SHA。
- Kubernetes 清单移除 ConfigMap 中的敏感占位字段，改由 Secret 和标准环境变量注入，并补齐容器安全上下文、只读根文件系统和资源限制。

### 报表、分享与嵌入

- 修复公共分享或嵌入报表中，数据大屏 A 跳转到已公开分享的数据大屏 B 时可能提示 `link token invalid` 的问题。
- 修复 hash 路由和嵌入场景下查询参数读取不完整，可能导致复制、跳转、分享或导入参数丢失的问题。
- 预览、分享、嵌入、导出和画布编辑态统一处理查询组件、组合组件、背景卡片和图表默认颜色，减少不同入口的展示差异。
- 修复后端打包前未清理旧前端静态资源的问题，避免历史 chunk 混入交付 JAR。

### 查询组件

- 时间范围查询支持只填写开始时间或结束时间，分别用于查询某个时间之后或之前的数据。
- 查询条件默认值里的固定日期支持直接键盘输入 `YYYY-MM-DD`，同时保留日期选择器输入方式。
- 修复日期动态值“今年”等规则在末尾条件中可能被判定为空条件的问题。

### 表格汇总

- 明细表和普通表的已有列汇总支持求和、平均值、最大值、最小值和自定义公式。
- 明细表支持新增虚拟汇总指标列，明细行显示空值占位，汇总行显示按过滤后全量数据计算的结果。
- 表格汇总列支持配置名称、指标字段、公式、数字格式、单位和空值展示，预览、分享、嵌入和导出保持一致。
- 修复表格导出汇总行在无维度列时可能用汇总标签覆盖首个指标汇总值的问题。
- 修复表格汇总行启用“总计”时可能影响图表数据加载的问题。
- 修复明细表和普通表的表头排序在部分事件对象下只显示空浮层、不触发排序的问题。

### 模板导入导出

- 修复模板导出后再导入时，历史或不完整组件配置可能导致编辑器空白、样式异常或静态资源缺失的问题。
- 修复模板导入流程依赖新窗口打开导致被浏览器拦截的问题，改为当前页内完成文件选择和后续编辑跳转。
- 修复模板导出未完整收集组合、Tab 和嵌套组件中的图片、视频、字体等静态资源的问题。
- 导入历史模板时补齐画布、组件、图表颜色、边框、下钻字段和静态资源默认值，提升跨版本模板兼容性。

### 画布编排

- 新增背景卡片能力，用于把多个图表或组件呈现为统一视觉区块。
- 保留历史组合组件兼容，支持无缝布局、背景色和层级配置。
- 优化画布组合相关配置面板文案、布局和入口位置，避免原始 i18n key、文字重叠和样式不一致。

### 构建与交付

- 后端和前端版本统一为 `1.5.14`，安装配置、Compose 模板、Kubernetes 清单、发布脚本和文档同步更新镜像标签。
- 应用镜像升级包和完整离线包均包含 `upgrade-sql/v1.5.13_to_v1.5.14.sql`。
- Release Guard、依赖安全扫描、代码扫描、密钥扫描、后端测试、前端类型检查、lint 和生产构建纳入发布前验证范围。

## 兼容性说明

- 本版本没有新增数据库表或字段；`upgrade-sql/v1.5.13_to_v1.5.14.sql` 仅清理仍保持旧默认值的模板中心访问密钥。
- 已有历史模板文件仍可导入，新旧模板导入流程保持兼容。
- 旧 AES-CBC 密文保留解密兼容；新产生的 AES-CBC 密文使用随机 IV 并附加 HMAC 完整性校验。
- 已有组合组件继续可用；推荐新建视觉组合时使用背景卡片承载统一背景和无缝布局。
- 已有分享链接、查询组件和表格配置不需要手动迁移；升级后建议重新验证关键报表的查询、跳转、导出和模板导入导出流程。

## 验证范围

- 后端安全定向测试：路径访问、SQL 单语句策略、SSRF、异常信息脱敏、WebSocket 身份、用户角色绑定和接口权限边界。
- 后端导出与 Excel 定向测试：导出任务、导出下载、图表导出模式、Excel 字段解析和资源释放相关路径。
- 报表功能定向测试：公共分享内部跳转 URL 构造、hash 查询参数读取、跳转配置 mapper、时间单侧过滤 SQL、动态日期规则和查询条件默认值。
- 表格定向测试：汇总公式优先级、虚拟汇总指标列、汇总行高度、表头排序浮层和导出汇总数据。
- 模板定向测试：本地导入流程、历史模板兼容、嵌套静态资源收集和导入默认值补齐。
- 画布定向测试：背景卡片、组合组件、画布组件默认值、图表颜色默认值和过滤后 Excel 导出。
- 前端验证：类型检查、lint、生产构建、公共跳转构造、表格汇总列、表格汇总高度和日期手动输入脚本测试。
- 安全验证：SAST、SCA、Release Guard、依赖告警、代码扫描和密钥扫描。
- 打包验证：后端复制前端静态资源前清理旧目录，`CoreApplication.jar` 未发现旧默认密码接口和旧文案。
- 交付包验证：应用镜像包和完整离线包均包含 `v1.5.13_to_v1.5.14.sql`，包内 README 写明升级 SQL 执行链路。
- 加密兼容验证：新 AES-CBC-HMAC 密文可正常解密，篡改密文会被拒绝，旧 AES-CBC 密文仍可读取。
- Kubernetes 验证：部署清单可渲染，渲染后的 YAML 可离线解析。

## 升级说明

全新安装不需要手动执行 `upgrade-sql/` 中的 SQL。

从 v1.5.13 升级到 v1.5.14 时，请先执行：

```text
upgrade-sql/v1.5.13_to_v1.5.14.sql
```

从 v1.5.8 升级到 v1.5.14 时，请执行同一个 `upgrade-sql/v1.5.13_to_v1.5.14.sql`，再替换前后端镜像或使用应用镜像升级包。

从 v1.5.7 升级到 v1.5.14 时，请先执行：

```text
upgrade-sql/v1.5.7_to_v1.5.8.sql
upgrade-sql/v1.5.13_to_v1.5.14.sql
```

从 v1.5.4 升级到 v1.5.14 时，请先执行：

```text
upgrade-sql/v1.5.4_to_v1.5.5.sql
upgrade-sql/v1.5.7_to_v1.5.8.sql
upgrade-sql/v1.5.13_to_v1.5.14.sql
```

执行升级 SQL 后，再替换 v1.5.14 前后端镜像。生产环境升级前建议完成元数据库备份、运行目录备份和关键资源导出。
