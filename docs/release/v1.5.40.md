# v1.5.40

发布日期：2026-08-31

v1.5.40 是 v1.5.39 之后的修复与诊断增强版本。修复柱状图辅助线图例盖住图表显示区域的问题；并为投产窗口日历远端不显示真实投产数据的问题加入更精准的前后端诊断日志（v1.5.39 诊断日志确认非数据集列权限、为组件特有问题，本次进一步定位）。**本版本没有新增数据库结构，无需执行升级 SQL。**

## Bug 修复

### 柱状图辅助线图例盖住图表显示区域
v1.5.39 新增的辅助线自定义图例采用绝对定位叠在图表容器内，但 g2plot 画布尺寸按容器 clientWidth/Height 计算（不减图例占位），导致图例盖住柱状图显示区域。

- **修复**：改用 g2plot 原生 `appendPadding` 机制让画布主动留出图例空间——`configAnalyse`/`configAnalyseHorizontal`（g2plot.ts）调 `mergeAssistLineAppendPadding` 把图例占位叠加到 `appendPadding`，画布在实例化时就缩小避开图例区；`renderAssistLineLegend`（common_antv.ts）图例 DOM 绝对定位到 appendPadding 留白区，二者不重叠
- 图例占位尺寸：横排 28px / 纵排 100px，与图例 DOM 共用同一常量
- 生效柱状图（bar）与条形图（horizontal-bar）

涉及：`common_antv.ts` 新增 `mergeAssistLineAppendPadding`/`normalizeAppendPadding`、`renderAssistLineLegend` 改纯绝对定位；`g2plot.ts` `configAnalyse`/`configAnalyseHorizontal` 叠加 appendPadding；`bar.ts`/`horizontal-bar.ts` 调用传入 newChart。

## 诊断增强

### 投产窗口日历远端不显示真实数据（第二轮定位）
v1.5.39 部署后后端日志确认：普通明细表用同一数据集绑同样列能正常显示，排除数据集列权限，问题为投产日历组件特有。后端 `[calcData] 轴=drill 被过滤` 为副现象（drillFields 残留），xAxis 未被过滤但 fields 仍空，真正根因待进一步定位。

本次加入更精准诊断：
- **前端 `Component.vue`**：calcData 传给后端前**清空 v.yAxis/v.extStack/v.drillFields**（原本只把 yAxis/extStack 并入 xAxis 但未清空残留，可能干扰后端 formatAxis），这本身可能是修复；加日志打印传出 view 的 viewId + 各轴字段数 + 字段详情（id/engineFieldName/name/groupType/summary）
- **后端 `ChartDataManage.java`**：calcData 列权限过滤日志加 viewId 便于精确对应投产日历请求；buildChart 出口加 INFO 日志打印 `xAxis字段数 / originData行数 / 返回fields / tableRow`，看清 xAxis 有字段但 fields 为何空

> 部署后看前端 `[DeployCalendar] 7. 传给后端的 view` 与后端 `[calcData] viewId=xxx buildChart出口`（按 viewId 对应投产日历请求），即可彻底定位根因。
