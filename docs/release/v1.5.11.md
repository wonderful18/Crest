# Crest v1.5.11 发布说明

发布日期：2026-06-14

Crest v1.5.11 是 v1.5.10 之后的稳定补丁版本，重点修复 Excel 数据源导入、数据集字段转换、应用模板导入映射和跳转设置相关问题。本版本没有新增数据库结构、系统参数或初始化数据变更；已有 v1.5.10 环境只需要替换前后端镜像或使用应用镜像升级包。

## 离线包

`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 修复内容

- 修复 Excel 数据源字段名较长、包含中文、重复列或空值占位符时，后续数据集转换和预览可能生成不稳定字段别名的问题。
- 修复 Excel 字段类型推断在整数、小数、日期文本、空值占位符和混合文本场景下不一致的问题。
- 修复基于 Excel 数据源的数据集执行日期函数转换时，目标数据库缺少 Crest 自定义函数导致 SQL 执行失败的问题。
- 修复数据集选择字段时，未持久化的字段 ID 为空时可能误继承其他字段物理别名的问题。
- 修复 SQL 单语句校验把字符串、注释或反引号字段中的分号误判为多语句的问题，同时继续拦截真正的多语句执行。
- 修复应用模板导入保存时，Excel 数据源对应的物理表名没有同步替换到数据集 SQL，导致导入后数据集无法直接运行的问题。
- 修复应用模板导入过程中进行 ID 映射时，Base64 编码的原始 SQL 被误替换的问题。
- 修复应用模板导入后组件 ID 类型不一致，导致部分图表数据和跳转配置无法稳定匹配的问题。
- 修复大屏或仪表盘“跳转设置”读取字段信息时，后端把字段物理类型当成字段分类读取，导致页面报“系统内部错误”的问题。
- 修复前端构建依赖安全告警，更新相关依赖锁定版本。

## 升级说明

全新安装不需要手动执行 `upgrade-sql/` 中的 SQL。

已有 v1.5.10 环境升级到 v1.5.11 时，只需要替换前后端镜像或使用 v1.5.11 应用镜像升级包，不需要新增升级 SQL。

从 v1.5.8 升级到 v1.5.11 时，只需要替换前后端镜像或使用应用镜像升级包，不需要新增升级 SQL。

从 v1.5.7 升级到 v1.5.11 时，请先执行：

```text
upgrade-sql/v1.5.7_to_v1.5.8.sql
```

执行升级 SQL 后，再替换 v1.5.11 前后端镜像。生产环境升级前建议完成数据库备份、运行目录备份和关键报表导出。

## 验证范围

本版本发布前执行以下检查：

- Excel 数据源表头识别、字段名生成、空值占位符、日期文本和数值类型推断单元测试；
- Excel 字段转换 SQL、日期函数翻译和数据集 SQL 预览单元测试；
- 应用模板导入时数据源表名映射、数据集 SQL 映射、组件 ID 映射和内部跳转配置回归测试；
- SQL 单语句校验的字符串、注释、反引号字段和多语句拦截测试；
- 跳转设置字段映射回归测试；
- 分享大屏打开、下钻弹窗和跳转设置接口验证；
- 后端编译和单元测试。
