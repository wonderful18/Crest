# Crest v1.5.13 发布说明

发布日期：2026-06-26

Crest v1.5.13 是 v1.5.12 之后的稳定补丁版本，修复大屏和仪表盘编辑态配置跳转设置时，目标图表列表没有读取 snapshot 数据的问题。本版本没有新增数据库结构、系统参数或初始化数据变更；已有 v1.5.12 环境只需要替换前后端镜像或使用应用镜像升级包。

## Release 附件

```text
crest-offline-v1.5.13-linux-amd64.tar.gz
crest-offline-v1.5.13-linux-arm64.tar.gz
crest-app-images-v1.5.13-linux-amd64.tar.gz
crest-app-images-v1.5.13-linux-arm64.tar.gz
crest-source-v1.5.13.tar.gz
crest-v1.5.13-checksums.txt
crest-app-images-v1.5.13-checksums.txt
```

GitHub Release 页面仍会自动提供 `Source code (zip)` 和 `Source code (tar.gz)`。`crest-source-v1.5.13.tar.gz` 是发布流程额外生成的命名源码包，便于归档和交付。

## 离线包

`crest-offline-*` 是完整离线安装包，包含安装脚本、配置模板、Docker Compose 文件、Crest 后端镜像、Crest 前端镜像、MySQL 镜像、可选监控组件配置、升级 SQL 和离线安装说明。

`crest-app-images-*` 是应用镜像升级包，仅包含 Crest 后端镜像、Crest 前端镜像、增量升级 SQL 和加载说明，不包含 MySQL、Prometheus、Grafana 镜像，也不包含完整安装脚本。已有环境只需要替换前后端应用服务时，可使用该包。

## 修复内容

- 修复大屏和仪表盘编辑态配置跳转设置时，目标图表列表仍读取正式表数据，导致未发布图表为空或不可选的问题。
- 修复目标图表列表为空时，追加外部参数或查询组件可能触发前端异常的问题。
- 收紧目标图表过滤逻辑，按组件配置中的图表 ID 精确匹配，避免字符串包含导致图表误入列表。

## 升级说明

全新安装不需要手动执行 `upgrade-sql/` 中的 SQL。

已有 v1.5.12 环境升级到 v1.5.13 时，只需要替换前后端镜像或使用 v1.5.13 应用镜像升级包，不需要新增升级 SQL。

从 v1.5.8 升级到 v1.5.13 时，只需要替换前后端镜像或使用应用镜像升级包，不需要新增升级 SQL。

从 v1.5.7 升级到 v1.5.13 时，请先执行：

```text
upgrade-sql/v1.5.7_to_v1.5.8.sql
```

执行升级 SQL 后，再替换 v1.5.13 前后端镜像。生产环境升级前建议完成数据库备份、运行目录备份和关键报表导出。

## 验证范围

- 后端定向 Maven 测试；
