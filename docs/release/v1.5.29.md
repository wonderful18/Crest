# v1.5.29 发布说明

v1.5.29 是 v1.5.28 之后的修复版本。修复数据大屏分享链接仍显示导出 Excel 按钮、图表字段显示名称无法留空两个问题。**本版本没有新增数据库结构,无需执行升级 SQL。**

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.29` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.29` |

## 修复

### 数据大屏分享链接仍显示导出 Excel 按钮

- 数据大屏(dataV)的分享链接中,点击「查看数据」放大后仍显示「导出 Excel」「导出原始明细」「导出 Excel(格式化)」按钮,不应出现。
- 修复:放大视图(`UserViewEnlarge.vue`)的三个导出按钮 `v-if` 条件增加 `dvInfo.type !== 'dataV'` 守卫,数据大屏场景下不再渲染导出按钮。`UserViewEnlarge.vue`。

### 图表字段显示名称无法留空

- 图表编辑器中重命名字段时,「显示名称」此前为必填(空值校验 `required`),且打开重命名弹窗时会用原字段名 `name` 自动回填 `chartShowName`,导致无法保存空显示名称。
- 修复:移除 `chartShowName` 的 `required` 校验规则(仅保留 200 字符上限),并移除 `showRename` 中 `chartShowName` 为空时自动回填 `name` 的逻辑。显示名称现可留空。`index.vue`。
