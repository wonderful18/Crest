# v1.5.21 发布说明

v1.5.21 是 v1.5.20 之后的缺陷修复版本，修复导出 Excel 时极小数值显示为科学计数法的问题。本版本没有新增数据库结构，无需执行升级 SQL。

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.21` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.21` |

## 修复明细

### 导出 Excel 极小数值显示科学计数法

- 导出 Excel 时，数值字段的极小值（如 `0.00000001`）在 Excel 中显示为科学计数法（`0E-8`/`1E-08`），而非 `0`。根因是 `createCellStyle` 在 `formatter` 为 null 或 `auto` 类型且值无小数点时使用 `General` 数字格式，Excel 对极小值默认以科学计数法显示。改为 `0.######` 格式：极小值四舍五入显示为 `0`，正常小数最多保留 6 位，避免科学计数法。
- 同步修复 `auto` 类型下 `split(".")` 正则 bug（`.` 是正则元字符，应转义为 `\\.`），此前 `valueSplit.length` 计算异常导致小数位格式串错误。

## 验证

- 后端 `core-backend` 编译通过；`ChartDataServerExportModeTest`（11）与 `ChartDataServerAuxiliaryHeaderTest`（1）共 12 个用例全部通过。

## 升级说明

- 从 v1.5.20 升级到 v1.5.21 只需要替换前后端镜像，不需要新增升级 SQL。

## 兼容性

- 仅影响导出 Excel 的数值单元格显示格式，不影响数据本身；正常数值显示行为不变。
