# Crest v2.0.3 发布说明

发布日期：2026-06-26

Crest v2.0.3 是 2.0 系列补丁版本，修复可视化跳转、OB-Oracle 最近使用和数据集缓存同步相关问题。本版本没有新增数据库结构、系统参数或初始化数据变更。

## 修复内容

- 修复大屏和仪表盘编辑跳转设置时，目标图表列表读取编辑态数据，导致已发布资源的目标图表为空或不一致的问题。
- 修复跳转目标图表 ID 使用字符串包含判断时，部分图表可能被误匹配的问题。
- 修复 OB-Oracle 系统库下新用户访问“最近使用”时，保留字段和 `UNION ALL` 类型推断导致查询失败的问题。
- 修复数据集缓存同步中旧执行状态覆盖新状态、增量配置切换和大数据集同步超时处理不稳定的问题。

## 升级说明

升级前必须完成以下准备：

- 备份 Crest 系统库；
- 备份运行目录和 `.env`；
- 确认当前系统库类型：MySQL、OceanBase MySQL 或 OceanBase Oracle；
- 确认所有 Crest 服务已停止或处于维护窗口。

从 v2.0.2 升级到 v2.0.3 时，不需要执行新增升级 SQL，只需要替换前后端镜像或使用 v2.0.3 应用镜像升级包。

全新安装仍使用安装包内的当前版本初始化 SQL；已有系统库不要执行一次性空库初始化 SQL。

```text
upgrade-sql/v2.0.3_full_schema_mysql.sql
upgrade-sql/v2.0.3_full_schema_ob_mysql.sql
upgrade-sql/v2.0.3_full_schema_ob_oracle.sql
```
