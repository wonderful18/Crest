# Crest v1.5.11-bgfix-10e7166 临时交付说明

发布日期：2026-06-24

`v1.5.11-bgfix-10e7166` 是基于 v1.5.11 维护线制作的临时内网交付版本，用于验证和交付上传背景图片展示修复。该版本不是正式 v1.5.12 Release，不占用后续正式 v1.5.12 版本号。

## 修复内容

- 修复数据大屏画布配置上传背景图片后，预览和展示样式没有稳定应用背景图的问题。
- 修复表单组件、查询框及通用组件背景配置使用外部图片时，背景图可能被组件内部样式覆盖的问题。
- 修复标题类组件背景图使用 CSS `background` 简写时，上传图片路径包含空格等字符可能解析不稳定的问题。

## 交付内容

本次临时 GitHub Release 上传应用镜像升级包：

```text
crest-app-images-v1.5.11-bgfix-10e7166-linux-amd64.tar.gz

```

现有应用镜像升级包脚本会同时包含前端和后端镜像。该问题只涉及前端，内网环境建议只替换前端镜像：

```text
ghcr.io/sevoniva/crest-web:v1.5.11-bgfix-10e7166
```

后端服务可以继续使用当前 v1.5.11 镜像，不需要执行 SQL。

## 升级说明

在内网服务器加载镜像包后，默认运行目录为 `/opt/crest`。只更新前端镜像：

```bash
cd /opt/crest
cp .env ".env.bak.$(date +%Y%m%d%H%M%S)"

if grep -q '^CREST_FRONTEND_IMAGE=' .env; then
  sed -i.bak 's#^CREST_FRONTEND_IMAGE=.*#CREST_FRONTEND_IMAGE=ghcr.io/sevoniva/crest-web:v1.5.11-bgfix-10e7166#' .env
else
  printf '\nCREST_FRONTEND_IMAGE=ghcr.io/sevoniva/crest-web:v1.5.11-bgfix-10e7166\n' >> .env
fi

docker-compose up -d --no-deps crest
```

生产环境升级前建议先备份运行目录和关键报表配置。
