# Crest v1.5.3 Release Notes

发布日期：2026-06-02

Crest v1.5.3 是 v1.5 系列的部署形态升级版本，面向全新私有化部署环境发布。本版本将应用拆分为后端服务镜像和前端网关镜像，配套更新单机安装、离线包、Kubernetes 清单、健康检查、网关配置和发布文档。历史版本 v1.5.0、v1.5.1、v1.5.2 仍保持当时的单镜像交付口径；从 v1.5.3 起，默认交付形态为 `crest-service` 后端镜像加 `crest-web` 前端镜像。

## 适用范围

- 适用于全新安装的企业内网、专有云和 Kubernetes 环境。
- 默认加载内置演示资源，便于首次部署后快速查看数据源、数据集、仪表盘、数据大屏和数据血缘链路。
- 生产环境如不需要演示资源，可在安装前设置 `CREST_LOAD_DEMO=false`，并将 `CREST_FLYWAY_LOCATIONS` 设为 `classpath:db/migration`。
- 本版本不提供从早期开发环境直接原地升级的承诺。迁移已有环境前，应先备份元数据库和运行目录，导出业务资源，再在新环境中导入。

## 发布镜像

```text
ghcr.io/sevoniva/crest-service:v1.5.3
ghcr.io/sevoniva/crest-service:main
ghcr.io/sevoniva/crest-web:v1.5.3
ghcr.io/sevoniva/crest-web:main
```

支持架构：

```text
linux/amd64
linux/arm64
```

后端镜像以 Alpine 为最终运行层，内置 jlink 裁剪后的 Java 21 runtime。前端镜像基于 Nginx Alpine，负责静态资源、API 转发、WebSocket 转发、安全响应头和请求追踪头。

## 主要变化

### 前后端分离交付

- 单机安装默认启动三个容器：`crest-service` 后端服务、`crest` 前端网关和 `mysql-crest` 元数据库。
- 后端镜像只包含应用服务、驱动和静态资源种子文件，不再承载前端运行时页面。
- 前端镜像只包含构建后的 Web 产物和 Nginx 网关配置。
- 离线包按架构保存 `crest-service`、`crest-web` 和 `mysql:8.0.43` 镜像归档。

### Kubernetes 部署

- `deploy/kubernetes/internal-mysql` 用于内置 MySQL 部署，包含 MySQL StatefulSet。
- `deploy/kubernetes/external-mysql` 用于外部 MySQL 部署，不创建 MySQL 资源。
- `crest-service` 后端和 `crest` 前端拆分为独立 Deployment，资源、探针和安全上下文分别配置。
- 前端 Nginx 配置由独立 ConfigMap 管理，避免 Docker Compose 和 Kubernetes 的服务发现配置混用。
- Kubernetes 清单不再生成占位 Secret。部署前应在目标 namespace 创建 `crest-db-secret`，或接入集群侧 Secret 管理系统。

### 健康检查

- 后端提供 `/api/v1/actuator/health/liveness` 和 `/api/v1/actuator/health/readiness`。
- `liveness` 只检查应用进程和 Web 容器响应，避免数据库短暂抖动造成误重启。
- `readiness` 校验元数据库连接，数据库不可用时摘除业务流量。
- 前端提供 `/healthz`，只检查 Nginx 网关可用性。
- Kubernetes startup、readiness 和 liveness 阈值按冷启动、Flyway 初始化和演示数据加载场景重新设置。

### 网关与运行基线

- Nginx 网关补齐 API 转发、WebSocket 转发、静态资源缓存、Source Map 拦截、隐藏文件拦截和安全响应头。
- 应用容器默认以非 root 用户 `10001:10001` 运行。
- Kubernetes 模板默认启用 `runAsNonRoot`、`allowPrivilegeEscalation: false`、`capabilities.drop: ALL` 和 `seccompProfile: RuntimeDefault`。
- 后端容器使用只读根文件系统，运行时写入目录通过 PVC 或 `emptyDir` 挂载。

### 公开分享

- 修复分享链接独立打开时被登录态拦截的问题。
- 分享页启动阶段只公开分享代理信息和分享校验接口。
- 后续图表数据请求继续使用受限分享 token，不放大为普通登录态。
- 已验证数据大屏分享链接可在未登录浏览器中直接打开并渲染。

### 文档与发布材料

- README、安装文档、Kubernetes 文档、开发说明、CHANGELOG 和 release notes 更新至 v1.5.3。
- 文档按当前产品形态描述，不保留临时改造记录。
- 历史版本发布说明保持原单镜像口径，不追溯改写。

## 安装注意事项

- 首次安装后请立即修改管理员密码。
- 生产环境必须设置高强度 `CREST_INITIAL_PASSWORD`、`CREST_DB_PASSWORD`、`CREST_AES_KEY` 和 `CREST_AES_IV`。
- 使用 Kubernetes 时，不要把真实 Secret、证书、kubeconfig 或生产导出的 YAML 提交到源码仓库。
- 使用外部网关终止 HTTPS 时，应在外部网关统一配置 TLS、HSTS、访问控制、限流和日志脱敏。
- 内置 MySQL 适合快速验证和单集群测试；正式环境建议优先使用外部托管 MySQL 或企业标准数据库服务。
