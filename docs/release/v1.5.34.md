# v1.5.34 发布说明

v1.5.34 是 v1.5.33 之后的新功能版本。新增明细表「单元格分组」手动合并能力,并新增「投产窗口日历」自定义图表组件。**本版本没有新增数据库结构,无需执行升级 SQL。**

## 镜像

| 镜像 | Tag |
| --- | --- |
| Crest 后端镜像 | `ghcr.io/sevoniva/crest-service:v1.5.34` |
| Crest 前端镜像 | `ghcr.io/sevoniva/crest-web:v1.5.34` |

## 新增功能

### 明细表「单元格分组」

- 现有「合并单元格」是按列值相同自动纵向合并,无法满足"把指定行的若干列横向合并成一个、并自定义显示内容"的需求。
- 新增「单元格分组」配置(明细表样式 → 表格单元格):按定位列的值匹配到第一个命中行,把该行起列到止列横向合并为一个单元格,并支持自定义显示文本;匹配值可从当前页数据中模糊搜索选择(也允许手动输入)。
- 与「合并单元格」(自动合并)可同时开启,手动分组优先;开启分组时与自动合并同等禁用斑马纹、行列冻结。
- 持久化到 `customAttr.tableCell.cellGroups`(规则式、按数据内容定位),翻页/换数据后按新数据重新匹配。

### 投产窗口日历组件

- 新增「投产窗口日历」自定义图表组件(`deploy-calendar`),以日历视图展示投产记录(周版/月版),支持按月份切换、回到今天、悬浮查看当日投产内容。
- 点击日历日期触发仪表板联动,联动查询目标明细表该日数据;再次点击同一日期清除联动、恢复默认全部明细表。
- 数据来源:绑定的数据集(投产日期列/投产内容列/版本类型列);未绑定时提供 mock 兜底。

## 技术说明

- 单元格分组:`ChartTableCellAttr` 新增 `cellGroups?: CellGroup[]`;`common_table.ts` 新增 `configCellGroups`,将规则转成 S2 `mergedCellsInfo` 矩形合并组,并在 `mergedCell` 回调用闭包 Map 覆盖自定义文本;手动组与自动组冲突时手动优先(剔除相交自动组),避免 S2 重叠渲染损坏。
- 投产窗口日历:`custom-component/deploy-calendar` 独立组件,通过 `dvMainStore.addViewTrackFilter`/`clearViewLinkage` 实现联动 toggle。
